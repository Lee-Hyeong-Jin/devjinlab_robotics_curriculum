# 0019. 공개 페이지의 HTML 은 공유 캐시에 올리지 않는다

- 상태: accepted
- 날짜: 2026-11-28
- 관련: ADR 0016(공개 콘텐츠), ADR 0018(기본 언어), docs/architecture/frontend.md §5.2, 이슈 #57

## 맥락

운영 사이트는 Cloudflare 뒤에 있는데 모든 페이지가
`cache-control: private, no-cache, no-store, max-age=0, must-revalidate` 로 내려간다. 익명 방문자의
공개 페이지(홈, 로드맵, 모듈, 레슨, 자료실)도 매번 원본이 그린다. 이슈 #57 은 이것을 엣지에서 잠깐
캐시하자고 제안했다.

2026-11-28 운영 측정(익명, 쿠키 없음, 한 번씩):

| 페이지 | HTML | gzip 전송 | 첫 바이트 |
|---|---|---|---|
| `/` | 152 KB | 28 KB | 0.31 s |
| `/roadmap` | 156 KB | 26 KB | 0.28 s |
| 레슨 | 161 KB | 34 KB | 0.25 s |
| `/resources` | 831 KB | 70 KB | 0.25 s |

원본 응답은 이미 0.25–0.4 초다. 웹 서버가 API 의 콘텐츠 응답을 5분간 캐시하므로, 페이지를 그리는 데
드는 것은 렌더링뿐이다. 눈에 띄는 문제는 자료실의 크기 하나였다.

## 선택지

- **A. 익명 응답을 `s-maxage` 로 엣지에 캐시한다.** 원본 부하와 첫 바이트가 줄어든다. 그러나:
  1. **로그인한 독자에게 익명 페이지가 나간다.** 같은 주소가 세션 유무와 저장된 언어(쿠키)에 따라
     다른 HTML 을 낸다. 캐시가 `Vary: Cookie` 를 지키지 않으면(Cloudflare 는 HTML 을 캐시하도록
     설정했을 때 기본적으로 지키지 않는다) 캐시된 익명 페이지가 로그인한 사람에게도 나간다. 쿠키가
     있으면 캐시를 건너뛰는 규칙은 이 저장소 밖(CDN 설정)에 있고, 틀리면 조용히 틀린다.
  2. **CSP nonce 가 재사용된다.** 스크립트는 요청마다 새 nonce 로 허용한다. HTML 과 헤더가 함께
     캐시되면 그 시간 동안 모든 방문자가 같은 nonce 를 받는다. nonce 는 추측할 수 없어야 의미가
     있다. 해시 기반 CSP 로 바꾸려면 Next.js 가 넣는 인라인 스크립트(요청마다 내용이 다르다)를
     해시할 수 없어 `unsafe-inline` 에 가까워진다.
  3. **방문 집계가 틀린다.** 방문은 웹 서버가 페이지를 줄 때 센다(ADR 0017). 엣지가 답하면 세지
     않는다.
- **B. 캐시하지 않고, 실제로 큰 것을 줄인다.** 자료실을 서버에서 걸러 한 페이지씩 내고, 페이지 크기에
  예산을 두어 다시 커지면 테스트가 잡는다.
- **C. A 를 기본은 끄고 설정으로 켤 수 있게.** 코드 경로와 CDN 규칙이 맞물려야 안전한 기능을 스위치
  하나로 내놓게 된다. 지금 필요로 하는 배포가 없다.

## 결정

**B.** HTML 은 지금처럼 `no-store` 로 둔다. 정적 자산(`/_next/static`, 글꼴, 아이콘)은 내용 해시가
붙어 있어 이미 오래 캐시된다.

- 자료실은 종류·검색어·페이지를 주소에 두고(`?kind=paper&q=kalman&page=2`) 서버에서 걸러 25개씩
  낸다: 831 KB → 약 200 KB(gzip 51 KB). 걸러진 화면을 링크로 공유할 수 있고, JavaScript 없이도
  동작한다.
- `web/e2e/smoke.spec.ts` 가 공개 페이지의 HTML 크기를 350 KB 로 제한한다.

## 결과

- 익명 방문도 원본이 그린다. 지금 규모(하루 수백 방문)에서는 문제가 아니다. 원본이 버거워지면 이
  결정을 다시 연다. 그때 필요한 것: (1) 세션·언어 쿠키가 있으면 캐시를 건너뛰는 CDN 규칙과 그것을
  확인하는 테스트, (2) nonce 를 쓰지 않는 CSP 로의 전환 검토, (3) 방문 집계를 엣지 로그나 브라우저
  비콘으로 옮기는 것.
- 레슨·로드맵 페이지의 150–170 KB 는 그대로다. 절반가량이 React 서버 컴포넌트 데이터의 중복인데,
  gzip 뒤 26–34 KB 라 지금은 손대지 않는다.
- Lighthouse 는 이 환경에서 실행하지 못했다. 위 수치는 `curl` 로 잰 크기와 첫 바이트 시간이다.
