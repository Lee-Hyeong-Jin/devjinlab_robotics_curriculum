# 0016. 커리큘럼을 익명 읽기 전용으로 공개한다 (`RC_PUBLIC_CONTENT`)

- 상태: accepted
- 날짜: 2026-11-12
- 관련: ADR 0009(세션 모델), ADR 0010(인증 구현), docs/api/role-matrix.md,
  docs/architecture/frontend.md, docs/ops/asvs-l2-checklist.md

## 맥락

플랫폼이 <https://learnrobotics.devjinlab.com> 으로 공개 배포됐고 `RC_AUTH_MODE=server` 다. 그래서
크롤러와 처음 온 사람이 보는 것은 **로그인 화면뿐**이다. 커리큘럼은 CC BY 4.0 이고 레슨 본문은
공개를 전제로 쓰였는데, 그중 아무것도 검색되거나 링크될 수 없다.

반대로 진행도·학습 노트·퀴즈 기록은 개인 데이터이고, `/admin` 과 감사 로그는 운영자 것이다.
이것들은 공개 대상이 아니다. 그래서 "무엇을 공개하는가"를 명시적으로 가르는 결정이 필요하다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 현행 유지(전부 로그인) | 결정·코드 변경 0 | 공개 콘텐츠가 공개되지 않는다. 검색·링크·인용이 불가능하다 |
| B. `RC_AUTH_MODE=local` 로 전환 | 익명 접근이 바로 된다 | **진행도가 전부 user 1 로 합쳐지고** 관리자 권한이 무인증으로 열린다. 공개 주소에서는 불가 |
| C. 정적 사이트(`rc site build`)를 따로 배포 | 크롤러에 완벽하고 서버 부하 0 | URL 이 둘로 갈리고(앱/사이트) 같은 레슨이 두 주소를 갖는다. 진행도가 붙은 화면과 분리된다 |
| D. 설정 플래그로 **커리큘럼 읽기만** 익명에 연다 | 한 URL 체계를 유지하면서 공개할 것만 공개한다. 기본값을 바꾸지 않아 기존 배포는 그대로 | 인증 경계가 엔드포인트별로 갈리므로 그 경계를 테스트로 고정해야 한다 |

D 를 택한다. C 는 정적 사이트를 버리는 결정이 아니다 — 정적 사이트는 오프라인·단일 사용자 용도로
계속 쓰이고(ADR 0004), 이 결정은 공개 **앱**이 자기 콘텐츠를 보여 줄 수 있게 하는 것이다.

## 결정

`RC_PUBLIC_CONTENT`(기본 `0`). `1` 이면 **커리큘럼 읽기만** 익명에게 열린다.

| 익명에게 열리는 것 (GET) | 계속 세션/PAT 가 필요한 것 |
|---|---|
| `/api/v1/courses`, `/courses/{id}` | `/api/v1/roadmap` — 호출자의 진행도를 담는다 |
| `/api/v1/modules/{id}` | `/api/v1/progress/*`(읽기·쓰기 전부) |
| `/api/v1/lessons/{id}` (본문·활동·자료·논문·문제 세트) | `/api/v1/lessons/{id}/quiz`, `/api/v1/quiz/*` |
| `/api/v1/resources`, `/api/v1/search` | `/api/v1/review/*`, `/api/v1/reports/*` |
| | `/api/v1/me/*`, `/api/v1/admin/*`, 모든 쓰기 |

- 경계는 **라우터 하나**에 있다: `content` 라우터만 `allow_public_read` 를 쓰고, 그것은 플래그가
  켜지고 메서드가 안전할 때만 익명을 통과시킨다. 나머지 라우터는 `get_principal` 그대로다.
  `/roadmap` 은 같은 라우터에 있지만 엔드포인트 수준에서 `get_principal` 로 되돌린다.
- **퀴즈는 공개하지 않는다.** `/lessons/{id}/quiz` 는 정답·해설을 담는 응답이고(응시 전에는 숨기는
  설계), 레슨 본문과 달리 공개 이득이 없다.
- **깨진 자격 증명은 여전히 401** 이다. 익명은 허용이지만 "누군가인 척하면서 토큰이 틀린 것"은
  허용이 아니다 — `Authorization` 헤더가 있으면 평소대로 검증한다.
- API·`/metrics`·DB 는 계속 비공개다. 익명 경로도 **웹 서버 측에서만** 호출된다(브라우저는 API 를
  직접 부르지 않는다, frontend.md §1). 즉 이 플래그는 "API 를 인터넷에 연다"는 뜻이 아니다.
- local 모드는 영향이 없다(이미 모든 요청이 user 1 이다).

## 웹 쪽 결과

- 콘텐츠 화면(레슨·모듈·자료실·로드맵)은 세션이 없어도 렌더된다. 진행도 호출은 익명에서 401 이
  나므로 **리다이렉트 대신 `null` 로 처리**하고 진행도 오버레이만 비운다.
- `/roadmap` 은 익명일 때 `/courses/{id}`(구조만)로 만든다. 진행도가 없으니 단계·모듈 구조만 보이고,
  그것이 크롤러와 처음 온 사람에게 필요한 것이다.
- 개인 화면(대시보드·복습·리포트·프로필·관리자·퀴즈)은 그대로 로그인으로 보내고 `noindex` 다.

## 결과

- 얻는 것: 레슨이 검색·링크·인용될 수 있다. URL 체계가 하나로 유지된다. 기본값이 `0` 이라 기존
  배포와 테스트는 바뀌지 않는다.
- 감수하는 것: 인증 경계가 엔드포인트별로 갈린다. 그래서 `tests/test_public_content.py` 가
  "커리큘럼은 열리고 **그 밖의 모든 것은 401**"을 경로 목록으로 고정한다 — 새 엔드포인트를 추가할 때
  이 목록에 넣는 것이 검토 항목이다.
- 콘텐츠가 익명에 열리면 크롤러 트래픽이 생긴다. 읽기 p95 는 목표의 1/6 이라(docs/operations/
  perf-baseline.md) 여유가 있지만, 캐시가 필요해지면 콘텐츠 엔드포인트가 먼저다(메모리 색인이므로
  CDN 캐시 헤더만으로도 충분할 것).
- 후속: 공개 레슨의 캐시 헤더(`Cache-Control: public, max-age=...`), 레이트 리밋이 필요해지면
  익명 경로부터.
