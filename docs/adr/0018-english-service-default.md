# 0018. 서비스의 기본 언어는 영어, 콘텐츠 원문과 CLI 는 한국어

- 상태: accepted
- 날짜: 2026-11-25
- 관련: ADR 0012(영어 번역 파일), ADR 0016(공개 콘텐츠), docs/architecture/frontend.md §5.2·§6

## 맥락

커리큘럼은 한국어로 쓰고 영어 번역을 옆 파일에 둔다(ADR 0012). 지금까지 "기본 언어"는 하나였고
한국어였다: 언어를 밝히지 않은 요청은 API 도 웹도 한국어로 답했다. 그래서 쿠키도 `Accept-Language`
도 보내지 않는 검색 크롤러는 모든 대표 주소(`/roadmap`, `/modules/…`)를 한국어로 읽었고, 영어
페이지는 `?lang=en` 이 붙은 주소에만 있었다. 영어 번역은 두 코스 155개 레슨 전부 있다. 서비스가
노리는 독자는 "learn robotics", "robotics tutorial" 로 찾아오는 사람을 포함한다.

"기본 언어"라는 말에는 서로 다른 두 가지가 섞여 있었다.

1. 콘텐츠를 쓰는 언어, 그리고 모든 메시지 키가 반드시 있는 카탈로그(다른 언어의 폴백).
2. 언어를 밝히지 않은 요청에 서비스가 답하는 언어.

## 선택지

- **A. 그대로 한국어.** 바꿀 것이 없다. 대표 주소가 한국어라 영어 검색에서 불리하다.
- **B. `DEFAULT_LANG` 을 통째로 `en` 으로.** 한 줄이지만 1번까지 바뀐다: 원문 언어 판정
  (`content/loader.py`, `content/models.py`), 폴백 카탈로그, CLI·정적 사이트·리포트의 출력이 모두
  영어가 된다. 원문은 여전히 한국어이므로 틀린 변경이다.
- **C. 둘을 나눈다.** 1번은 `DEFAULT_LANG = "ko"` 그대로, 2번은 새 값 `SERVICE_DEFAULT_LANG = "en"`
  (API 는 `RC_DEFAULT_LANG` 로 바꿀 수 있음, 웹은 `DEFAULT_LOCALE`).
- **D. C + 웹에서 `Accept-Language` 협상을 없앤다.** 주소와 쿠키만 언어를 정한다. 한 주소가 항상 한
  언어라 가장 단순하지만, 한국어 브라우저로 처음 온 사람도 영어를 먼저 본다.

## 결정

**C.** 언어를 밝히지 않은 요청에 API 와 웹은 영어로 답한다. 언어를 정하는 순서는 그대로다:
`?lang=` → 저장된 선택(쿠키, 프로필) → `Accept-Language` → 기본값(이제 영어).

- 웹: `DEFAULT_LOCALE = 'en'`. 대표 주소(canonical)와 `x-default` 는 영어 페이지이고, 한국어 페이지는
  `?lang=ko` 주소가 대표다. `hreflang` 은 `en` → 맨 주소, `ko` → `?lang=ko`.
- API: `Settings.default_lang`(`RC_DEFAULT_LANG`, 기본 `en`). `?lang=` 도 `Accept-Language` 도 없는
  요청, 지원하지 않는 언어만 적은 요청, `Accept-Language: *` 가 여기에 해당한다. 웹은 항상
  `?lang=` 을 붙여 부르므로 영향을 받는 것은 직접 호출하는 클라이언트와 스크립트다.
- 한국어 브라우저(`Accept-Language: ko`)는 계속 한국어를 받는다. D 를 고르지 않은 이유다: 지금 쓰는
  한국어 독자의 화면을 바꾸지 않는다.
- CLI, 정적 사이트(`rc site build`), 로컬 리포트는 한국어 그대로다(`--lang en`, `RC_LANG=en`).
- 언어를 고정한 주소(`?lang=ko`)에서 언어 전환기를 쓰면 고정을 풀고 다시 읽는다. 전에는 주소가
  쿠키를 이겨서 전환이 먹지 않았다.

## 결과

- 검색 엔진이 보는 대표 주소의 언어가 한국어에서 영어로 바뀐다. 이미 색인된 주소는 다시 수집될
  때까지 한국어 제목·설명으로 남고, 한국어 페이지는 `?lang=ko` 주소로 다시 색인된다. 한동안 순위가
  흔들릴 수 있다. 되돌리기 비싼 이유가 이것이다.
- 언어를 밝히지 않고 API 를 부르던 스크립트는 영어 응답을 받는다. 한국어가 필요하면 `?lang=ko` 나
  `Accept-Language: ko` 를 보내거나, 서버에 `RC_DEFAULT_LANG=ko` 를 준다.
- 프로필에 언어를 저장하지 않은 계정의 메일(인증, 비밀번호 재설정)은 요청의 언어를 따른다. 웹에서
  요청하면 화면 언어다.
- `DEFAULT_LANG` 을 "서비스 기본"의 뜻으로 쓰면 안 된다. 원문 언어와 폴백 카탈로그만 뜻한다
  (`tests/test_default_language.py` 가 두 값을 고정한다).
