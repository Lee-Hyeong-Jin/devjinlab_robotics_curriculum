# 강건·확률 최적 제어

## 전제와 기호

앞 여섯 레슨은 모델이 **정확하다**고 가정했다. `c4-dp-lqr-lqg` 는 Doyle 1978 로 그 가정의
대가를 보였고, `c4-mpc` 는 열린 문제 3 으로 "모델 오차 아래의 재귀적 실현가능성"을 남겼다.
이 레슨이 그 질문의 답이다. 불확실성을 다루는 길이 둘이다 — **최악의 경우**(집합으로 보고
게임으로 푼다)와 **분포**(확률로 보고 기댓값을 최소화한다). 둘은 다른 보장을 주고 다른
비용을 치른다. 권장 선수는 앞 여섯 레슨이다.

이 레슨이 추가로 전제하는 것:

- 편미분방정식: 1차 HJ 방정식의 점성 해(`c4-dp-lqr-lqg` R2 의 실패 모드에서 소개했다).
  존재·유일성 이론은 쓰지 않고 **특성화**만 쓴다.
- 게임 이론: 2인 영합 게임, 안장점, minimax 와 maximin 의 차이(상·하 값).
- 확률: 조건부 기댓값, 가법 잡음과 **승법** 잡음의 구별(`c4-dp-lqr-lqg` R5 의 실패 모드 2).
- 집합 연산: 민코프스키 합·차(Pontryagin 차), 불변 집합(`c4-mpc` R1).

표기 규약:

| 기호 | 뜻 |
|---|---|
| $d \in \mathbb{D}$ | 교란(disturbance). 최악의 경우 관점에서는 **적대적**이다 |
| $\xi$ | 확률 잡음. 가법은 $x^+ = f(x,u) + \xi$, 승법은 $f$ 가 $\xi$ 에 곱으로 의존 |
| $\mathcal{T}$ | 목표 집합(target). $\mathcal{T} = \{x : l(x) \le 0\}$ |
| $\mathcal{R}(T)$ | **후방 도달가능 관(BRT)**: 시간 $T$ 안에 $\mathcal{T}$ 에 **보낼 수 있는** 상태 |
| $V(x,\tau)$ | 레벨셋 값 함수. $\mathcal{R}(\tau) = \{x : V(x,\tau) \le 0\}$ |
| $H(x,p)$ | 해밀토니안 $\min_u \max_d\, p^\top f(x,u,d)$ |
| $\gamma$ | $\mathcal{H}_\infty$ 성능 수준. 교란에 붙는 벌점 $-\gamma^2\lVert d\rVert^2$ |
| $\mathcal{Z}$ | 튜브 MPC 의 **오차 집합**(mRPI). 공칭과 실제의 차가 머무는 집합 |
| $\ominus$ | Pontryagin 차. $\mathbb{X} \ominus \mathcal{Z} = \{x : x + z \in \mathbb{X}\;\forall z \in \mathcal{Z}\}$ |

**두 관점의 대비**(이 레슨의 지도):

| | 최악의 경우(강건) | 분포(확률) |
|---|---|---|
| 불확실성 모형 | 집합 $d \in \mathbb{D}$ | 분포 $\xi \sim p$ |
| 푸는 것 | 2인 영합 게임 | 기댓값 최소화 |
| 보장 | **모든** $d$ 에 대해 성립 | 평균적으로 최적 |
| 대가 | 보수적 — 성능을 깎는다(R2) | 꼬리 위험에 약하다 |
| 대표 | HJI 도달가능성, 미니맥스 DDP, 튜브 MPC | iLQG, 확률 MPC |

## 핵심 결과

괄호 안은 유도 깊이 등급이다(D0 인용 / D1 골격 / D2 완전 유도 / D3 증명 —
`f0-how-to-read-this-track` 레슨의 "유도 깊이 등급" 절).

- **R1 (HJI 와 도달가능 집합) [D3]** — 후방 도달가능 관은 HJI **변분부등식**
  $$
  \min\Big\{\frac{\partial V}{\partial \tau} - H\big(x, \nabla V\big),\; V - l \Big\} = 0,
    \qquad V(x,0) = l(x), \qquad H(x,p) = \min_{u}\max_{d}\, p^\top f(x,u,d) \tag{1}
  $$
  의 점성 해의 **영 아래집합**이다: $\mathcal{R}(\tau) = \{x : V(x,\tau) \le 0\}$.
  부등식의 두 항은 각각 "도달 가능성이 퍼진다"와 "한 번 도달하면 유지된다"를 뜻한다
  (Mitchell et al. 2005).
- **R2 (가산·동일채널 교란의 정확한 환원) [D2]** — 교란이 제어와 **같은 채널로 가산**으로
  들어오면($\dot{x}_2 = u + d$, $\lvert u\rvert \le 1$, $\lvert d \rvert \le D$)
  $$
  H(x,p) = p_1 x_2 + \min_{\lvert u\rvert\le1} p_2 u + \max_{\lvert d\rvert\le D} p_2 d
    = p_1 x_2 - (1-D)\lvert p_2\rvert \tag{2}
  $$
  이므로, **강건 도달가능 집합은 제어 한계를 $1-D$ 로 줄인 공칭 집합과 정확히 같다.**
  이중 적분기에서는 공칭 집합이 `c4-pontryagin-indirect` R3 의 bang-bang 해로 닫혀 있어
  $$
  T^*_a(x) = \frac{1}{a}\Big(x_2 + 2\sqrt{a x_1 + \tfrac12 x_2^2}\Big)
    \;\;\big(x_1 \ge -\tfrac{x_2\lvert x_2\rvert}{2a}\big), \qquad
    \mathcal{R}_D(T) = \{x : T^*_{1-D}(x) \le T\} \tag{3}
  $$
  라는 **해석적 검증자**를 얻는다. 레벨셋 수치해는 이것과 대조해야 한다.
- **R3 (미니맥스 게임 Riccati 와 $\mathcal{H}_\infty$ 한계) [D2]** —
  $\dot x = ax + bu + cd$, $J = \int(qx^2 + ru^2 - \gamma^2 d^2)dt$ 의 게임 HJI 는
  $$
  k\,P^2 - 2aP - q = 0, \qquad k := \frac{b^2}{r} - \frac{c^2}{\gamma^2},
    \qquad P = \frac{a + \sqrt{a^2 + kq}}{k} \tag{4}
  $$
  이고, $\gamma$ 를 줄이면(= 교란에 더 강건하면) $P$ 가 커져 **성능이 깎인다**.
  $k \le 0$, 즉 $\gamma \le c\sqrt{r}/b$ 에서는 **해가 존재하지 않는다** — 교란이 이긴다.
  이것이 $\mathcal{H}_\infty$ 성능 한계이고, $\gamma \to \infty$ 에서 (4)는
  `c4-dp-lqr-lqg` 의 LQR 로 되돌아간다.
- **R4 (승법 잡음에서 확실성 등가가 깨진다) [D2]** — `c4-dp-lqr-lqg` R5 는 **가법** 잡음에서
  최적 이득이 잡음과 무관함을 보였다. 잡음이 제어에 **곱으로** 들어오면
  ($x^+ = Ax + (B + C\xi)u$, $\xi \sim \mathcal{N}(0,1)$) 기댓값에
  $C^2 u^2$ 항이 살아남아
  $$
  K = \frac{PAB}{R + P\,(B^2 + C^2)} \tag{5}
  $$
  가 되고, 분모의 $PC^2$ 때문에 이득이 **줄어든다**(신중, caution). 재현 과제에서
  $13.90\%$ 축소와 몬테카를로 기대 비용 개선을 측정한다.
- **R5 (튜브 MPC: 공칭과 오차의 분리) [D1]** — 선형계에 유계 교란이 있으면, 상태를
  공칭 $\bar{x}$ 와 오차 $e = x - \bar{x}$ 로 쪼개고 오차를 고정 피드백 $K$ 로 묶으면
  $e^+ = (A+BK)e + w$ 이므로 오차는 **최소 강건 불변 집합**(mRPI) $\mathcal{Z}$ 에 머문다.
  그러면 공칭 문제의 제약을 $\mathbb{X} \ominus \mathcal{Z}$, $\mathbb{U} \ominus K\mathcal{Z}$
  로 **조이면** 실제 궤적이 원래 제약을 만족하고, `c4-mpc` R1 의 재귀적 실현가능성이
  외란 아래로 옮겨진다(Mayne et al. 2005). **[D1]**

## 유도

### R2 — 환원과 해석적 검증자

레벨셋 수치해는 검증하기 어렵다. 그래서 **답을 아는 문제**를 하나 만든다.

이중 적분기에 제어와 교란이 같은 채널로 들어오는 경우를 본다:

$$
\dot{x}_1 = x_2, \qquad \dot{x}_2 = u + d, \qquad
  \lvert u \rvert \le 1, \quad \lvert d \rvert \le D < 1. \tag{6}
$$

(1)의 해밀토니안을 계산한다. 제어는 $V$ 를 **줄이려** 하고 교란은 **키우려** 하므로

$$
H(x,p) = p_1 x_2 + \underbrace{\min_{\lvert u\rvert\le1} p_2 u}_{=\,-\lvert p_2\rvert}
  + \underbrace{\max_{\lvert d\rvert\le D} p_2 d}_{=\,+D\lvert p_2\rvert}
  = p_1 x_2 - (1 - D)\lvert p_2 \rvert,
$$

즉 (2)다. **이것은 교란이 없고 제어 한계가 $1-D$ 인 문제의 해밀토니안과 글자 그대로
같다.** 두 문제의 HJI 가 같고 초기 조건도 같으므로 값 함수가 같고, 따라서 도달가능 집합도
같다. 교란 $D$ 는 **제어 권한을 $D$ 만큼 빼앗는 것과 정확히 등가**다.

**왜 이 환원이 특별한가**: 일반적으로 $\min_u\max_d$ 는 $\max_d\min_u$ 와 다르고(상·하 값),
교란을 "제어 권한의 축소"로 바꿀 수 없다. 환원이 되는 것은 (6)에서 $u$ 와 $d$ 가
**같은 벡터장 방향**으로 가산으로 들어오기 때문이다. 그러면 최적자와 적대자가 같은 축에서
싸우므로 안장점이 존재하고($p_2$ 의 부호가 둘의 최적 선택을 동시에 결정한다) 두 값이 같다.
$u$ 와 $d$ 가 서로 다른 방향으로 들어오면 이 환원은 성립하지 않는다(문제 P5).

**해석적 검증자.** 환원 덕분에 공칭 문제의 닫힌 해를 쓸 수 있다.
`c4-pontryagin-indirect` R3 에서 $\lvert u\rvert \le 1$ 의 최소 시간 이중 적분기가
bang-bang 이고 스위칭이 최대 1회임을 증명했다. 한계가 $a$ 면 스위칭 곡선이
$x_1 = -x_2\lvert x_2\rvert/(2a)$ 이고 최소 시간은 (3)이다(반대쪽 분지는
$T^*_a = (-x_2 + 2\sqrt{-ax_1 + \tfrac12 x_2^2})/a$). 재현 과제의 조건 1 이
$T^*_1(1,0) = 2$, $T^*_1(0.5,-1) = 1$, $T^*_1(-2,-1) = 1 + \sqrt{10}$ 로
`c4-pontryagin-indirect` 의 손계산과 일치하는지 확인한다 — **두 레슨이 같은 수를 공유한다.**

그러면 $\mathcal{R}_D(T) = \{x : T^*_{1-D}(x) \le T\}$ 이고, $T = 3$ 에서 $[-3,3]^2$ 안의
면적은

| $D$ | 유효 한계 $1-D$ | $\mathcal{R}_D(3)$ 의 면적 |
|---|---|---|
| $0$ | $1.0$ | $13.8439$ |
| $0.1$ | $0.9$ | $12.2047$ |
| $0.3$ | $0.7$ | $8.6691$ |
| $0.5$ | $0.5$ | $4.4817$ |

이다($601\times601$ 격자). **교란이 커지면 도달가능 집합이 줄어든다** — 강건성의 대가가
면적으로 보인다.

**가정이 깨지는 곳**: (2)는 $D < 1$ 을 썼다. $D \ge 1$ 이면 $1 - D \le 0$ 이고 교란이
제어를 완전히 상쇄할 수 있어 도달가능 집합이 목표 집합 자체로 쪼그라든다(또는 비게 된다).
이것이 R3 의 임계 $\gamma$ 와 같은 현상의 집합 버전이다. 또 (3)은 목표가 **원점**일 때의
최소 시간이다. 목표가 반지름 $r$ 의 원판이면 그만큼 시간이 줄어들므로, (3)으로 집합을
판정할 때는 그 차이를 고려해야 한다(재현 과제의 진단표).

### R3 — 미니맥스 게임 Riccati

스칼라 게임을 끝까지 푼다. $\dot x = ax + bu + cd$,
$J = \int_0^\infty (qx^2 + ru^2 - \gamma^2 d^2)\,dt$ 에서 **제어는 최소화, 교란은 최대화**한다.
$-\gamma^2d^2$ 항이 교란에 붙는 벌점이고, $\gamma$ 가 작을수록 교란이 **싸져** 강해진다.

값 함수를 $V = Px^2$ 로 두면 $V_x = 2Px$ 이고 HJI 는

$$
\min_u \max_d \Big[ qx^2 + ru^2 - \gamma^2 d^2 + 2Px\,(ax + bu + cd) \Big] = 0.
$$

**내부 최적화.** $u$ 에 대해: $ru^2 + 2Pxbu$ 를 최소화하므로 $u^* = -Pbx/r$.
$d$ 에 대해: $-\gamma^2d^2 + 2Pxcd$ 를 최대화하므로 $d^* = Pcx/\gamma^2$.
(둘 다 2차이고 각각 볼록·오목이므로 안장점이 존재한다 — $r > 0$ 과 $\gamma^2 > 0$ 이 그 조건이다.)

**대입.** 각 항을 모은다:

$$
\begin{aligned}
&qx^2 + r\Big(\frac{Pbx}{r}\Big)^2 - \gamma^2\Big(\frac{Pcx}{\gamma^2}\Big)^2
  + 2Px\Big(ax - \frac{b^2Px}{r} + \frac{c^2Px}{\gamma^2}\Big) \\
&= qx^2 + \frac{P^2b^2x^2}{r} - \frac{P^2c^2x^2}{\gamma^2}
  + 2aPx^2 - \frac{2P^2b^2x^2}{r} + \frac{2P^2c^2x^2}{\gamma^2} \\
&= x^2\Big[q + 2aP - \frac{P^2b^2}{r} + \frac{P^2c^2}{\gamma^2}\Big] = 0,
\end{aligned}
$$

즉 $kP^2 - 2aP - q = 0$ 에서 $k = b^2/r - c^2/\gamma^2$ — (4)다. 안정화 근은
$P = (a + \sqrt{a^2 + kq})/k$ 이고, 폐루프는 $a - b^2P/r + c^2P/\gamma^2$ 다.

**$a=b=c=q=r=1$ 에서 수치로 읽는다.**

| $\gamma$ | $k$ | $P$ | 폐루프 | 비고 |
|---|---|---|---|---|
| $\infty$ | $1.00000$ | $2.4142135624$ | $-1.4142135624$ | **공칭 LQR** ($1+\sqrt2$, $-\sqrt2$) |
| $4.0$ | $0.93750$ | $2.5514038301$ | $-1.3919410907$ | |
| $2.0$ | $0.75000$ | $3.0971675407$ | $-1.3228756555$ | |
| $1.5$ | $0.55556$ | $4.0449944321$ | $-1.2472191289$ | |
| $1.2$ | $0.30556$ | $7.0121752366$ | $-1.1426091001$ | |
| $1.0$ | $0$ | — | — | **해 없음** |
| $0.9$ | $-0.23457$ | — | — | **해 없음** |

**세 가지를 읽는다.** ⓐ $\gamma \to \infty$ 에서 $P = 1 + \sqrt2$, 폐루프 $-\sqrt2$ 로
`c4-dp-lqr-lqg` 의 P4 와 **정확히 같다** — 교란 벌점을 무한히 키우면 교란이 0 이 되어
LQR 로 되돌아간다. ⓑ $\gamma$ 를 줄이면 $P$ 가 단조 증가한다($2.41 \to 7.01$). $P$ 는
비용이므로 **강건성은 성능을 깎는다**. ⓒ $\gamma \le c\sqrt{r}/b = 1$ 에서 $k \le 0$ 이고
(4)에 양의 해가 없다 — 그 성능 수준은 **달성 불가능**하다. 이것이
$\mathcal{H}_\infty$ 설계에서 $\gamma$ 를 이분법으로 찾는 이유다(달성 가능한 최소 $\gamma$ 를
찾는다).

**가정이 깨지는 곳**: (i) 안장점의 존재에 $\gamma^2 > 0$ 과 $r > 0$ 을 썼다. $r \to 0$
(싼 제어)이면 $k \to \infty$ 로 $P \to 0$ 이 되어 교란이 무력해지는데, 이는 제어가 무한히
강한 비현실적 극한이다. (ii) 유한 지평선에서는 (4)가 시변 게임 Riccati 미분방정식이 되고,
$k \le 0$ 이어도 **유한 시간 동안은** 해가 존재할 수 있다 — "해가 없다"는 무한 지평선의
진술이다. (iii) 이 유도는 교란이 **상태를 알고** 즉시 반응한다고 가정한다(완전 정보 게임).
교란이 상태를 모르면 더 약해지고 $\gamma$ 한계가 느슨해진다.

### R4 — 승법 잡음에서 확실성 등가가 깨진다

`c4-dp-lqr-lqg` R5 는 **가법** 잡음에서 최적 이득이 잡음 공분산과 무관함을 보였다(확실성
등가). 그 증명의 핵심은 "가법 잡음이 2차 비용에 더하는 것은 $u$ 에 무관한 trace 항뿐"이었다.
잡음이 제어에 **곱으로** 들어오면 그 문장이 거짓이 된다.

스칼라 이산계로 본다. $\xi_k \sim \mathcal{N}(0,1)$ 이 서로·시간에 독립이고

$$x_{k+1} = A x_k + (B + C\xi_k)\,u_k. \tag{7}$$

값 함수를 $V(x) = Px^2$ 로 두고 한 단계 Bellman 을 쓴다. $\xi$ 에 대한 기댓값에서
$\mathbb{E}[\xi] = 0$, $\mathbb{E}[\xi^2] = 1$ 이므로

$$
\mathbb{E}\big[(Ax + (B + C\xi)u)^2\big]
  = (Ax + Bu)^2 + C^2u^2. \tag{8}
$$

**이 $C^2u^2$ 항이 $u$ 에 의존한다** — 가법 잡음이었다면 상수였을 자리다. 그러므로

$$
\min_u \Big\{ Qx^2 + Ru^2 + P\big[(Ax+Bu)^2 + C^2u^2\big]\Big\}
$$

를 $u$ 로 미분해 0 으로 두면

$$
2Ru + 2PB(Ax + Bu) + 2PC^2 u = 0
  \;\Longrightarrow\; u^* = -\frac{PAB}{R + P(B^2 + C^2)}\,x,
$$

즉 (5)다. 분모에 $PC^2$ 가 더 있으므로 **이득의 크기가 줄어든다**. 해석은 "제어를 쓰면
잡음도 함께 들어오므로 덜 쓴다"이고, 이것을 **신중한 제어**(cautious control)라 한다.
Riccati 도 바뀐다: $P = Q + PA^2 - PAB\,K$ 에 (5)의 $K$ 를 쓴다.

**수치**($A = 1.1$, $B = 1$, $C = 0.6$, $Q = R = 1$):

| | $P$ | $K$ |
|---|---|---|
| 확실성 등가($C$ 를 무시) | $1.7737707217$ | $0.7034279289$ |
| 잡음 인식(5) | $2.1919289904$ | $0.6056537807$ |

이득이 $13.90\%$ 줄었고, 두 이득을 (7)의 실제 계에서 몬테카를로로 돌리면
(샘플 $4\times10^5$, 60스텝) 기대 비용이

$$
\text{확실성 등가 } 2.258600 \quad > \quad \text{잡음 인식 } 2.198433
$$

로 **잡음 인식 이득이 $2.7\%$ 낫다**. 즉 승법 잡음에서 확실성 등가는 **최적이 아니다** —
`c4-dp-lqr-lqg` R5 의 실패 모드 2 가 수로 확인된 것이다. 이것이 iLQG(Todorov & Li 2005)가
공분산을 역방향 패스에 끌어들이는 이유다: `c4-ilqr-ddp` (2)의 $Q_{uu}$ 에
$\sum_i C_i^\top V'_{xx} C_i$ 꼴의 항이 더해진다.

**가정이 깨지는 곳**: (i) (8)은 $\xi$ 가 $x$·$u$ 와 **독립**임을 썼다. 잡음이 상태에
의존하면(상태 의존 공분산) 기댓값에 교차항이 남아 2차형식이 닫히지 않고, 값 함수가 2차가
아니게 된다. (ii) 이 유도는 **위험 중립**(기댓값 최소화)이다. 꼬리 위험을 신경 쓰면
위험 민감 목적($\exp$ 변환)이나 CVaR 을 써야 하고, 그러면 이득이 또 달라진다 — 위험 민감
제어는 $\mathcal{H}_\infty$ 와 수학적으로 연결된다(문제 P7). (iii) $R + P(B^2+C^2) > 0$ 이
필요하다. $C$ 가 매우 크면 이득이 0 으로 가고 **제어를 포기**하는 것이 최적이 된다 —
제어 채널이 잡음으로 망가진 경우이고, 그때는 제어가 아니라 하드웨어를 고쳐야 한다.

### R5 — 튜브 MPC (골격)

`c4-mpc` 는 교란이 없다고 가정했다. R1 의 2단계("직전 해의 궤적이 실제로 일어난다")가
교란 아래에서 깨지므로 재귀적 실현가능성 증명이 무효가 된다. 튜브 MPC 가 그것을 고친다.

**분리.** 실제 계를 $x^+ = Ax + Bu + w$ ($w \in \mathbb{W}$ 유계)로 두고, 공칭 계
$\bar{x}^+ = A\bar{x} + B\bar{u}$ 를 따로 돌린다. 제어를

$$u = \bar{u} + K(x - \bar{x}) \tag{9}$$

로 쓰면 오차 $e = x - \bar{x}$ 는

$$e^+ = (A + BK)e + w \tag{10}$$

를 따른다. $\rho(A+BK) < 1$ 이면 (10)의 궤적은 **최소 강건 불변 집합**
$\mathcal{Z} = \bigoplus_{i\ge0}(A+BK)^i\mathbb{W}$ 에 머문다(초기 오차가 $\mathcal{Z}$ 에
있으면 영원히 머문다 — $\mathcal{Z}$ 가 (10)에 대해 불변이기 때문이다).

**제약 조이기.** 실제 상태가 $\mathbb{X}$ 를 만족해야 하는데 $x = \bar{x} + e$ 이고
$e \in \mathcal{Z}$ 이므로, 공칭이 **조인** 제약

$$\bar{x} \in \mathbb{X} \ominus \mathcal{Z}, \qquad \bar{u} \in \mathbb{U} \ominus K\mathcal{Z} \tag{11}$$

을 만족하면 실제가 원래 제약을 만족한다. 그러면 공칭 문제는 **교란이 없는** MPC 이므로
`c4-mpc` R1·R2 를 그대로 적용할 수 있고, 재귀적 실현가능성과 안정성(오차 집합까지의 수렴)이
복원된다(Mayne et al. 2005).

**대가**는 (11)의 조이기다. $\mathbb{W}$ 가 크면 $\mathcal{Z}$ 가 커지고
$\mathbb{X} \ominus \mathcal{Z}$ 가 **비어 버릴 수 있다** — R2 의 "$D \ge 1$ 이면 집합이
쪼그라든다"와 같은 현상이다. 그리고 $\mathcal{Z}$ 는 무한 민코프스키 합이라 정확히 계산할 수
없고 외근사를 쓴다(그만큼 더 보수적이 된다).

**가정이 깨지는 곳**: (10)의 깔끔한 분리는 **선형계**와 **가법·유계** 교란에서만 성립한다.
비선형계에서는 오차 동역학이 공칭 궤적에 의존해 $\mathcal{Z}$ 가 궤적마다 달라지고, 학습된
모델의 오차는 **상태에 의존**해 유계 집합으로 감싸기 어렵다(`c4-mpc` 의 열린 문제 3).

## 증명 스케치

### R1 — 도달가능 관은 HJI 점성 해의 영 아래집합이다 [D3]

**가설**
H1: $f(x,u,d)$ 가 $x$ 에 대해 리프시츠, $u \in \mathbb{U}$·$d \in \mathbb{D}$ 는 콤팩트,
$f$ 가 $(u,d)$ 에 연속.
H2: $l$ 이 리프시츠이고 $\mathcal{T} = \{l \le 0\}$ 이 닫힌집합.
H3 (Isaacs 조건): $\min_u\max_d\,p^\top f = \max_d\min_u\,p^\top f$ — 즉 상·하 값이 같다.
H4: 교란은 제어의 현재 값을 알지 못한다(비예측 전략, nonanticipative strategies).

**결론** C: (1)의 점성 해 $V$ 에 대해
$\mathcal{R}(\tau) = \{x : V(x,\tau) \le 0\}$ 이고, 그 집합의 상태에서는 **모든** 허용
교란에 대해 목표에 도달시키는 제어가 존재한다.

**전략**: 동적 계획법으로 $V$ 의 **의미**를 정하고(최악의 경우 최소 도달 비용), 그 함수가
(1)을 점성 해의 의미로 만족함을 보인 뒤, 비교 원리로 유일성을 얻는다. 핵심은
"$\min$ 과 변분부등식의 두 항이 각각 무엇을 뜻하는지"다.

1. **값 함수의 정의.** 비예측 전략 $\sigma$ 에 대해
   $$
   V(x,\tau) := \inf_{u(\cdot)}\;\sup_{d(\cdot)}\;\min_{s \in [0,\tau]} l\big(x(s)\big)
   $$
   로 둔다. 안쪽 $\min_s$ 가 **"구간 중 한 번이라도 목표에 들어갔는가"**를 재는 장치다
   ($\min_s l \le 0 \iff$ 어느 시각엔가 $\mathcal{T}$ 에 있었다). 따라서
   $V(x,\tau) \le 0$ 이 곧 "최악의 교란에도 $\tau$ 안에 도달시킬 수 있다"다.
2. **동적 계획 원리.** $\delta$ 만큼 흐른 뒤의 값으로 쓰면
   $$
   V(x,\tau) = \min\Big\{\, l(x),\;\; \inf_u \sup_d V\big(x + f\delta,\; \tau - \delta\big)\Big\} + o(\delta).
   $$
   바깥 $\min$ 의 첫 항이 "지금 이미 목표 안"이고 둘째 항이 "한 걸음 더 가서 본다"다.
3. **극한을 취한다.** 둘째 항을 1차 전개하면
   $\inf_u\sup_d\big[V + \nabla V^\top f\,\delta - V_\tau \delta\big]$ 이고, H3 으로
   $\inf\sup = H$ 를 쓸 수 있다. 2단계의 $\min$ 구조를 유지하며 $\delta \to 0$ 하면
   $$\min\big\{\,V_\tau - H(x,\nabla V),\;\; V - l\,\big\} = 0,$$
   즉 (1)이다. **두 항의 뜻**: 첫 항이 0 이면 도달 가능성이 그 점에서 "전파"되고, 둘째 항이
   0 이면 $V = l$ 로 **고정**된다(이미 목표 안이므로 더 좋아지지 않는다). $\min$ 이 그 둘 중
   유리한 쪽을 고른다 — 이것이 집합이 **줄어들지 않는** 관(tube)이 되는 이유다.
4. **점성 해로 읽어야 하는 이유.** $V$ 는 일반적으로 미분 가능하지 않다
   (`c4-dp-lqr-lqg` R2 의 실패 모드와 같은 이유 — 서로 다른 최적 전략이 만나는 면에서
   꺾인다). 3단계의 전개는 그 면 밖에서만 고전적으로 유효하고, 전체 영역에서는 시험 함수를
   쓰는 점성 해의 정의로 바꿔 읽는다.
5. **유일성과 특성화.** 1차 HJ 방정식의 비교 원리로 (1)의 점성 해가 유일하므로, 1단계의
   값 함수가 **그** 해다. 따라서 그 영 아래집합이 도달가능 관이다. **C**.
   (생략: 비교 원리의 증명과 비예측 전략에 대한 동적 계획 원리의 엄밀한 성립 —
   [Mitchell et al. 2005](https://doi.org/10.1109/TAC.2005.851439) §II–§III 와 그 참고문헌.)

**가설을 지우면 어디서 무너지는가**

- **H3(Isaacs 조건)을 지우면**: $\min_u\max_d \ne \max_d\min_u$ 이고 3단계에서 어느 쪽을
  $H$ 로 쓸지가 갈린다. 두 선택이 **서로 다른 집합**을 준다 — 상 값은 "교란이 먼저 보는"
  보수적 집합, 하 값은 "제어가 먼저 보는" 낙관적 집합이다. 안전 보증은 **보수적 쪽**을 써야
  한다. (6)처럼 $u, d$ 가 같은 채널로 가산이면 Isaacs 조건이 성립해 둘이 같다(R2).
- **H4(비예측)를 지우면**: 교란이 제어의 현재 값을 **보고** 반응하면 더 강해져 집합이 더
  작아진다. 반대로 교란이 상태도 모르면(개루프 교란) 집합이 커진다. **"강건 집합"은 교란의
  정보 구조에 따라 다르다** — 논문을 읽을 때 반드시 확인할 항목이다.
- **$\min$ 의 둘째 항을 지우면**(즉 $V_\tau = H$ 만 풀면): 목표에 들어간 뒤 다시 나가는
  궤적이 값에 반영되어 "한 번이라도 도달"이 아니라 "끝에 도달"을 재게 된다. 그러면
  도달가능 **집합**(reach set, 시각 $\tau$ 에 정확히)이 되고 **관**(tube, $\tau$ 안에 언제든)이
  아니다. 안전 분석에서는 거의 항상 관이 필요하다.
- **차원을 키우면**: 이 특성화는 차원에 무관하게 **참**이지만 계산은 격자에서 $O(n^d)$ 다.
  $d \gtrsim 6$ 에서 실용성이 사라진다 — 이론이 맞는데 쓸 수 없는 전형적인 경우이고,
  열린 문제 1 이다.

## 문제 세트

해답 방침은 문제마다 적어 두었다. 난이도: ★ 15분 / ★★ 1시간 / ★★★ 하루 이상.

**P1 (유도, ★, R4)** (8)을 끝까지 전개하고, 잡음이 **가법**($x^+ = Ax + Bu + C\xi$)일 때는
$u$ 에 의존하는 항이 남지 않음을 보여라. 그 다음 두 경우의 Riccati 를 나란히 써라.
*해답 스케치*: 가법이면 $\mathbb{E}[(Ax+Bu+C\xi)^2] = (Ax+Bu)^2 + C^2$ 로 상수가 더해지므로
최소화자가 바뀌지 않는다(확실성 등가). 승법이면 $C^2u^2$ 가 남아 분모에 $PC^2$ 가 들어간다.
Riccati 는 가법에서 $P = Q + PA^2 - P^2A^2B^2/(R+PB^2)$ 에 상수항이 따로 누적되고, 승법에서는
분모가 $R + P(B^2+C^2)$ 로 바뀐다.

**P2 (유도, ★★, R3)** (4)를 다변수로 확장하라. $\dot x = Ax + Bu + Cd$,
$J = \int(x^\top Qx + u^\top Ru - \gamma^2 d^\top d)dt$ 의 게임 Riccati 를 쓰고,
$k$ 에 해당하는 양이 무엇이 되는지, 그리고 해 존재 조건이 어떤 행렬 부등식이 되는지 적어라.
*해답 스케치*: $A^\top P + PA + Q - P(BR^{-1}B^\top - \gamma^{-2}CC^\top)P = 0$ 이고
$k$ 의 자리에 $BR^{-1}B^\top - \gamma^{-2}CC^\top$ 가 온다. 존재 조건은 그 행렬이
**양정부호**(또는 적어도 안정화 해가 존재하도록 충분히 양)이어야 한다는 것이고, 스칼라의
$k > 0$ 이 행렬 부등식 $BR^{-1}B^\top \succ \gamma^{-2}CC^\top$ 로 일반화된다.

**P3 (증명, ★★★, R1)** 증명 스케치 3단계의 변분부등식에서 **둘째 항을 지운** 방정식
$V_\tau = H(x,\nabla V)$ 의 해가 도달가능 **집합**(시각 $\tau$ 에 정확히 목표에 있는 상태)을
주고, $\min$ 이 있는 (1)의 해가 도달가능 **관**을 준다는 것을 증명하라.
*해답 스케치*: 전략은 1단계의 값 함수에서 $\min_{s\in[0,\tau]}$ 를 $l(x(\tau))$ 로 바꾼 뒤
같은 동적 계획 전개를 반복하는 것이다. 핵심 관찰: $\min_s$ 가 있으면 값이 $\tau$ 에 대해
**단조 비증가**이므로 집합이 단조 증가하고, 그 단조성이 변분부등식의 둘째 항으로 나타난다.
단조성이 없으면 집합이 $\tau$ 에 대해 커졌다 작아질 수 있다 — 구체적 예를 하나 만들라.

**P4 (계산, ★, R3)** $a=b=c=q=r=1$ 에서 (4)를 $\gamma = 4, 2, 1.5, 1.2$ 에 대해 풀고
$P$ 와 폐루프 극점을 소수 10자리까지 구하라. 임계 $\gamma$ 를 구하고, $\gamma \to \infty$
극한이 `c4-dp-lqr-lqg` P4 와 일치하는지 확인하라.
*정답*: $k = 1 - 1/\gamma^2$, $P = (1 + \sqrt{1+k})/k$.
$\gamma=4$: $k=0.9375$, $P=2.5514038301$, 극점 $-1.3919410907$.
$\gamma=2$: $k=0.75$, $P=3.0971675407$, 극점 $-1.3228756555$.
$\gamma=1.5$: $k=0.5\overline{5}$, $P=4.0449944321$, 극점 $-1.2472191289$.
$\gamma=1.2$: $k=0.3055\overline{5}$, $P=7.0121752366$, 극점 $-1.1426091001$.
임계 $\gamma = c\sqrt{r}/b = 1$ (허용오차 $10^{-9}$). $\gamma\to\infty$ 에서
$P = 1+\sqrt2 = 2.4142135624$, 극점 $-\sqrt2$ ✓.
*검산*: 각 $P$ 를 (4)에 넣어 잔차 $< 10^{-12}$ 를 확인하고, $P$ 가 $\gamma$ 에 대해
단조 감소(즉 $\gamma$ 가 작아질수록 $P$ 증가)인지 본다.

**P5 (계산, ★★, R2)** (2)의 환원이 $u$ 와 $d$ 가 **다른 채널**로 들어오면 성립하지 않음을
보여라. 구체적으로 $\dot x_1 = x_2 + d$, $\dot x_2 = u$ ($\lvert u\rvert\le1$,
$\lvert d\rvert\le D$)의 해밀토니안을 계산하고, 그것이 어떤 제어 한계의 공칭 문제와도
같지 않음을 설명하라.
*정답*: $H = p_1x_2 + D\lvert p_1\rvert - \lvert p_2\rvert$. 교란 항이 $\lvert p_1\rvert$ 에
붙고 제어 항은 $\lvert p_2\rvert$ 에 붙으므로 **두 항을 합칠 수 없다** — 어떤 $a$ 에 대해서도
$p_1x_2 - a\lvert p_2\rvert$ 꼴이 되지 않는다. 따라서 (3)의 해석적 검증자를 쓸 수 없고
레벨셋을 실제로 풀어야 한다.
*검산*: $D = 0$ 에서 두 해밀토니안이 같아지는지 확인하고, $D > 0$ 에서
$\lvert p_1\rvert$ 항이 $x_2$ 와 독립적으로 값을 키우는 것을 본다.

**P6 (구현, ★★★, R1·R2)** HJI 레벨셋 솔버를 구현해 (6)의 강건 도달가능 관을 계산하고
(3)의 해석적 집합과 대조하라. **경고**: 저자의 Lax-Friedrichs 구현은 수렴하지 않았다 —
$[-3,3]^2$, $T=2$, 목표 원판 $r=0.25$ 에서 상대 대칭차가 격자 $n = 101 \to 201 \to 401
\to 801$ 에 대해 $0.593 \to 0.169 \to 0.240 \to 0.429$ 로 **한 번 줄었다가 다시 커졌다**
($D=0$; $D=0.3$ 도 $0.609 \to 0.202 \to 0.376 \to 0.641$ 로 같은 양상). 수렴하는 구현을
만들라.
*루브릭*: ⓐ 상대 대칭차가 네 개 이상의 격자에서 **단조 감소**함을 보인다 ⓑ 감소율을 보고하고
쓰인 스킴(상류 차분의 종류, 소산 계수, CFL 수)을 명시한다 ⓒ 저자 구현이 왜 발산했는지
진단해 한 문단으로 쓴다(후보: 소산 항의 부호, 도메인 전체에서 잡은 $\alpha_1 = \max\lvert x_2\rvert$,
경계 조건의 외삽, 목표 원판과 원점 기반 $T^*$ 의 불일치) ⓓ `helperOC` 같은 기존 구현과
대조해도 좋다(그 경우 자기 구현과의 차이를 보고한다).

**P7 (반례, ★★, R3·R4)** "강건하게 설계하면 평균 성능도 좋아진다"가 틀렸음을 **두 가지
방식**으로 보여라: (i) R3 에서 $\gamma$ 를 줄일 때 $P$ 가 커지는 것(= 공칭 비용이 나빠짐),
(ii) 교란이 실제로는 없는 계에 미니맥스 제어를 쓰면 LQR 보다 비용이 높은 것을 수치로.
*성질 체크리스트*: (i) 은 P4 의 표를 쓰고 $P$ 가 공칭 비용임을 명시한다. (ii) 는 $d \equiv 0$
인 계에 $\gamma = 1.2$ 의 미니맥스 이득을 넣어 LQR 이득과 비용을 비교한다. 확인할 성질:
강건 설계는 **최악의 경우**를 보증하는 대가로 평균을 포기한다 — 두 지표를 혼동하지 않는다.
보너스: 위험 민감 제어가 $\mathcal{H}_\infty$ 와 연결되는 지점을 한 줄로 쓰라.

**P8 (논문, ★★, R1·R4·R5)** Mitchell et al. 2005 §II–§IV, Todorov & Li 2005 §II–§III,
Mayne et al. 2005 §2–§4 를 읽고 ⓐ Mitchell 등이 쓰는 교란의 정보 구조(비예측 전략)가 이
레슨 H4 와 같은지 ⓑ Todorov-Li 의 iLQG 가 승법 잡음을 역방향 패스의 어느 항에 넣는지
ⓒ Mayne 등의 $\mathcal{Z}$ 계산이 실제로는 어떤 외근사를 쓰는지 각각 3문장 이내로 쓰라.
*루브릭*: ⓐ 는 비예측 전략과 Isaacs 조건을 짚으면 통과. ⓑ 는 $Q_{uu}$ 에 더해지는
공분산 항을 식으로 쓰면 통과. ⓒ 는 유한 합 + 스케일링으로 외근사한다는 점과 그 보수성을
짚으면 통과. "집합을 계산한다"만 쓰면 미달.

| 집합 밖에서도 최악의 교란으로 도달한다 | 바깥 판정의 여유가 부족하다(원판 반지름만큼 시간이 절약된다) | 바깥 여유를 $+1.0$ 로 키운다. 저자 구현은 $+0.4$ 에서 $6/564$ 가 새어 나왔다 |
| 미니맥스 피드백이 공칭 스위칭 곡선을 쓴다 | 강건 값 함수의 곡선은 **$1-D$** 로 계산해야 한다 | 곡선의 분모가 $2(1-D)$ 인지 확인한다. 제어 **크기**는 1 이다 |
| $\gamma$ 가 작을 때 $P$ 가 음수로 나온다 | $k \le 0$ 인데 근의 공식을 그대로 썼다 | $k > 0$ 을 먼저 검사하고, 아니면 "해 없음"을 보고한다 |
| 승법 잡음에서 두 이득이 같게 나온다 | 잡음을 가법으로 구현했다($Ax + Bu + C\xi$) | (7)대로 $\xi$ 가 $u$ 에 **곱해지는지** 확인한다 |
| 몬테카를로 비용 차이가 잡음에 묻힌다 | 표본이 적다 | $4\times10^5$ 이상 쓰고, 같은 난수로 두 이득을 비교한다(공통 난수) |

## 열린 문제

- **(열린 문제) 레벨셋의 차원 장벽** — R1 의 특성화는 차원에 무관하게 참이지만 격자 계산은
  $O(n^d)$ 로 $d \gtrsim 6$ 에서 끝난다. 사족·휴머노이드($d \gtrsim 20$)의 안전 집합을
  HJI 로 계산하는 것은 불가능하다. 현재 접근: 계를 분해해 저차원 부분문제로 쪼개는 방법과
  신경망으로 값 함수를 근사하는 방법([Bansal et al. 2017](https://doi.org/10.1109/CDC.2017.8263977)
  §IV 가 정리한다). 비어 있는 자리: 근사된 값 함수가 **보수적인 쪽으로** 틀렸다는 것을
  인증하는 방법 — 안전 보증은 한쪽으로만 틀려야 쓸 수 있다.
- **(열린 문제) 최악의 경우와 분포 사이** — 최악의 경우는 보수적이고(R3 의 $P$ 증가) 기댓값은
  꼬리에 약하다. 둘 사이를 매개하는 위험 척도(CVaR, 분포 강건 최적화)가 제안되었지만,
  로보틱스 규모에서 **계산 가능하면서 보증이 있는** 중간 지점이 확립되지 않았다.
  현재 접근: 위험 민감 제어($\exp$ 변환)와 $\mathcal{H}_\infty$ 의 수학적 연결, 모멘트 기반
  분포 강건 MPC. 비어 있는 자리: 교란 집합·분포를 **데이터에서** 추정했을 때의 보증.
- **(열린 문제) 학습된 모델 오차의 집합 표현** — R5 의 튜브는 $w \in \mathbb{W}$ 유계를
  요구하지만, 학습된 동역학의 오차는 상태에 의존하고 꼬리가 두껍다. 상태 의존 튜브를 쓰면
  $\mathcal{Z}$ 가 궤적마다 달라져 불변성 논증이 복잡해진다. 현재 접근: 가우시안 과정의
  신뢰구간을 $\mathbb{W}$ 로 쓰는 방법과 등각 예측(conformal prediction) 기반의 집합 추정.
  비어 있는 자리: 유한 표본 보증과 재귀적 실현가능성을 **동시에** 주는 구성
  (`c4-mpc` 의 열린 문제 3 과 같은 자리이고, `c8-rl-theory` 에서 학습 쪽에서 다시 만난다).
- **(열린 문제) 접촉이 있는 계의 강건성** — 앞 레슨이 보인 대로 접촉은 전환면 근방에서
  미분 가능하지 않고, 전환 **순서**가 교란에 따라 바뀔 수 있다. 그러면 R5 의 오차 집합이
  모드마다 달라지고 민코프스키 합이 모드 수열마다 생긴다. 현재 접근: 모드별 튜브와
  전환면 근방의 보수적 여유. 비어 있는 자리: 모드 수열의 변화를 **집합으로** 감싸는 방법 —
  보행 로봇의 외란 복원력(push recovery)을 보증하려면 이 문제를 풀어야 한다.

## 이 단계 공부법

1. **두 관점의 표를 먼저 외운다 (20분)** — "전제와 기호"의 최악/분포 대비 표를 종이에 옮긴다.
   이 레슨의 모든 결과가 그 두 열 중 하나에 속하고, 혼동이 이 주제의 가장 흔한 오류다
   (강건 설계가 평균도 좋게 한다는 착각 — 퀴즈 q6).
2. **해석적 검증자를 먼저 만든다 (50분)** — 조건 1 을 **먼저** 구현한다. (3)의 $T^*$ 가
   `c4-pontryagin-indirect` 의 세 손계산 값을 재현하는 것을 보면, 레벨셋 같은 복잡한 계산에
   들어가기 전에 **답을 아는 문제**를 손에 쥐게 된다. 연구에서 수치 코드를 쓰는 올바른
   순서가 이것이다.
3. **환원을 손으로 유도한다 (40분)** — (2)를 직접 쓰고, $u$ 와 $d$ 가 같은 채널일 때만
   두 항이 합쳐지는 것을 확인한다(P5 로 반례를 본다). 이 한 줄이 "교란 = 제어 권한의 축소"
   라는 직관을 정확한 명제로 바꾼다.
4. **몬테카를로로 집합을 확인한다 (70분)** — 조건 2 가 이 레슨의 핵심 경험이다. 특히 ⓒ
   (집합 밖에서 **무교란이면** 일부가 도달한다)를 꼭 측정하라. 공칭 집합과 강건 집합의 차이가
   "교란이 협조해야만 되는 상태"라는 것을 숫자로 보는 순간, 강건성이 무엇을 사고 무엇을
   파는지가 분명해진다.
5. **게임 Riccati 를 끝까지 전개한다 (50분)** — R3 의 대입 계산을 손으로 한다. 부호를 한
   번 틀리면 $k$ 가 뒤집혀 결론이 반대가 되므로, $\gamma\to\infty$ 에서
   `c4-dp-lqr-lqg` 의 $1+\sqrt2$ 가 나오는지로 검산한다. 그 다음 임계 $\gamma$ 를 구하고
   표를 만든다(P4).
6. **확실성 등가를 깨뜨린다 (60분)** — 조건 4 를 구현한다. 가법과 승법을 **같은 코드에서
   스위치로** 바꿔 두면, 가법에서 두 이득이 같고 승법에서 갈라지는 것을 바로 볼 수 있다.
   공통 난수로 비교해야 2.7% 차이가 잡음에 묻히지 않는다.
7. **튜브는 골격만, 논문으로 채운다 (60분)** — R5 는 D1 이다. (9)–(11)의 구조만 손에 넣고
   Mayne et al. §2–§3 으로 세부를 채운다. `c4-mpc` R1 의 다섯 단계와 나란히 놓고 **무엇이
   바뀌었는지**(2단계의 "직전 궤적이 실제로 일어난다"가 어떻게 수선되는지)를 한 문단으로 쓴다.
8. **레벨셋은 선택이지만 권한다 (옵션, 하루)** — 문제 P6 이다. 저자 구현이 수렴하지 않았다는
   사실까지 함께 주었으니, 수렴하는 구현을 만드는 것은 좋은 연구 연습이다. 해석적 검증자가
   있으므로 **오라클이 있는 디버깅**이 되고, 이것은 실제 연구에서 드문 사치다.
9. **논문은 집합 → 분포 → 실무 순서로 (150분)** — Mitchell et al.(집합·게임) →
   Todorov & Li(분포) → Mayne et al.(실무 MPC). 처음 둘이 이 레슨의 두 열에 각각 대응하고,
   셋째가 둘을 실제 제어기로 만든다. 논문당 1페이지 노트는 **반드시** 쓴다.
10. **모듈을 닫는다 (40분)** — 이 레슨이 C4 의 마지막이다. 일곱 레슨의 "열린 문제"를 모아
    읽고, 반복해서 나온 자리를 세 개 골라 적어라(전역 최적성 인증, 비매끄러움에서의 기울기,
    학습된 모델 아래의 보증). 그 셋이 2026년 로보틱스 최적 제어의 실제 전선이고,
    `s2-planning-through-contact`·`s3-legged-underactuated`·`c8-rl-theory` 가 각각
    그 전선을 이어받는다.
