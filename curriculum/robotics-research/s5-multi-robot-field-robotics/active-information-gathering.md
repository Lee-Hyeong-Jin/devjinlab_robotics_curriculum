# 능동 지각·정보 수집

## 전제와 기호

`c5-factor-graphs-map` 의 정보행렬 $\Lambda = \Sigma^{-1}$ 과 선형화된 측정의 정보 기여
$A^\top R^{-1} A$ 를 그대로 쓴다. `c8-mdp-pomdp-bellman` 의 순차 결정 관점은 R1 의 마지막 논점
(선형 가우시안에서는 개루프 계획이 최적이다)에서 쓴다.

| 기호 | 뜻 |
|---|---|
| $x \in \mathbb{R}^d$ | 추정 대상(지도·표적·상태). 사전분포 $x \sim \mathcal{N}(0, \Sigma_0)$, $\Lambda_0 = \Sigma_0^{-1}$ |
| $\mathcal{V}$ | 후보 측정(센서 위치·시점) 집합, $\lvert\mathcal{V}\rvert = m$ |
| $y_i = A_i x + n_i$ | 후보 $i$ 의 측정. $n_i \sim \mathcal{N}(0, R_i)$ |
| $S \subseteq \mathcal{V}$ | 선택한 측정 집합. 예산은 $\lvert S\rvert \le k$ |
| $\Lambda_S$ | $S$ 를 받은 뒤의 정보행렬 $\Lambda_0 + \sum_{i\in S} A_i^\top R_i^{-1} A_i$, $\Sigma_S = \Lambda_S^{-1}$ |
| $f(S)$ | 목적함수 $= I(x; y_S)$ (상호정보). $f(\emptyset) = 0$ |
| $\Delta_j(S)$ | 한계 이득 $f(S \cup \{j\}) - f(S)$ |
| $A \preceq B$ | PSD 순서 ($B - A \succeq 0$) |

**문제.** $\lvert S\rvert \le k$ 아래 $f(S)$ 를 최대화한다. 후보 $m$ 개에서 $k$ 개를 고르는 조합이
$\binom{m}{k}$ 이므로 완전 탐색은 지수적이고, 실제로 이 문제는 NP-난해다. 이 레슨의 주제는
**탐욕 알고리즘이 왜, 얼마나 잘 하는가**다.

## 핵심 결과

괄호 안은 유도 깊이 등급이다(D0 인용 / D1 골격 / D2 완전 유도 / D3 증명 —
`f0-how-to-read-this-track` 레슨의 "유도 깊이 등급" 절).

- **R1 (선형 가우시안 상호정보는 로그 행렬식이다) [D2]** —
  $$
  f(S) = I(x; y_S) = \tfrac12 \log\det\Lambda_S - \tfrac12\log\det\Lambda_0
  = \tfrac12 \log\det\!\left(I + \Sigma_0\sum_{i\in S} A_i^\top R_i^{-1}A_i\right). \tag{1}
  $$
  두 가지가 따라온다. ⓐ $f$ 는 **D-최적 설계**의 목적함수와 같다(`c4` 의 실험 설계와 같은 대상).
  ⓑ (1)은 **측정값 $y$ 에 의존하지 않는다** — 선형 가우시안에서는 무엇을 볼지 미리 정해도
  실제로 보고 나서 정하는 것과 같은 정보를 얻으므로, **개루프 계획이 최적**이다
  (`atanasov2015-decentralized-active` 가 쓰는 분리 성질). 비선형·비가우시안에서는 이것이
  깨지고 폐루프(POMDP)가 필요하다.
- **R2 (조건부 독립이면 상호정보는 단조 submodular 다) [D3]** — 한계 이득이
  $$
  \Delta_j(S) = \tfrac12\log\det\!\left(I + R_j^{-1}A_j \Sigma_S A_j^\top\right) \tag{2}
  $$
  이고, $S \subseteq T \Rightarrow \Lambda_S \preceq \Lambda_T \Rightarrow \Sigma_S \succeq \Sigma_T$
  이므로 $\log\det$ 의 PSD 단조성에서 $\Delta_j(S) \ge \Delta_j(T) \ge 0$ 이다. 즉
  **단조성과 submodularity 가 공분산의 PSD 순서 하나에서 나온다**. 수렴 없는 세 줄 증명이고,
  실측에서 4000회 시행 중 위반 0건이다.
- **R3 (탐욕 알고리즘의 $(1-1/e)$ 보장) [D3]** — $f$ 가 단조 submodular 이고 $f(\emptyset)=0$ 이면
  탐욕해 $S_k$ 가
  $$
  f(S_k) \;\ge\; \left(1 - \left(1-\tfrac1k\right)^{\!k}\right) f(\mathrm{OPT}) \;\ge\; \left(1-\tfrac1e\right) f(\mathrm{OPT}) \tag{3}
  $$
  를 만족한다(Nemhauser–Wolsey–Fisher). 증명의 전부는 "$\mathrm{OPT}$ 의 원소들의 한계 이득 합이
  남은 간극을 덮는다 + 탐욕은 그중 최대를 고른다"이고, 거기서 간극의 기하적 감소가 나온다.
- **R4 (그 한계는 이 문제군에서 36%p 느슨하다) [D2]** — (3)은 **단조 submodular 함수 클래스
  전체**에 대한 최악의 경우다. 재현 과제의 실측: 가우시안 상호정보 50개 무작위 사례에서
  탐욕/최적의 평균이 $0.9941$, 최소 $0.9621$, **60% 는 정확히 최적**이다 — 한계
  $0.6321$ 보다 36%p 높다. 반대로 최대 피복(max coverage)의 고전적 타이트 족에서는 비율이
  $k=2,5,10,20$ 에 대해 $0.7500, 0.6724, 0.6515, 0.6417$ 로 **$1-(1-1/k)^k$ 를 소수 셋째 자리까지
  달성**한다. 따라서 (3)을 "탐욕의 기대 성능"으로 인용하면 틀린다 — 그것은 **보장**이고
  타이트 족은 피복에서 온다.
- **R5 (잡음이 상관되면 submodularity 가 깨진다) [D2]** — R2 는 측정이 상태에 대해 **조건부
  독립**이라는 가정에 의존한다. 재현 과제의 반례: $x\in\mathbb{R}^2$ 에서 $x_1+x_2$ 와 $x_1-x_2$ 를
  재는 두 센서의 잡음 상관계수를 $\rho = 0.99$ 로 두면
  $f(\{1\}) = f(\{2\}) = 1.5726$ 인데 $f(\{1,2\}) = 5.1027$ 이다. 즉 2번의 한계 이득이 단독
  $1.5726$ 에서 1번 뒤 $3.5302$ 로 **늘어난다**(시너지 $+1.9576$). submodularity 가 깨졌으므로
  (3)의 보장이 사라진다. **센서 네트워크의 잡음이 상관되어 있다면 탐욕의 보장을 인용할 수 없다.**
- **R6 (통신 한 라운드가 보장을 산다) [D2]** — 로봇 2대가 각 2개를 고르는 문제에서,
  **순차** 선택(뒤 로봇이 앞 로봇의 선택을 본다)은 중앙 탐욕과 **같은 알고리즘**이므로 (3)이
  그대로 적용되고 실측 평균이 $0.9968$ (최소 $0.9692$)다. **동시** 선택(통신 없음)은 둘이 같은
  센서를 고르므로 상수 배 보장이 없고, 실측 평균 $0.5654$, **최소 $0.4386$ 으로 $1/2$ 아래**다.
  그리고 submodularity 는 공짜 가속도 준다 — lazy 탐욕(CELF)이 평가 횟수를 $225.0 \to 98.9$
  ($2.28\times$)로 줄이면서 30/30 **같은 선택**을 낸다.

## 유도

### R1 — 상호정보가 로그 행렬식이 되는 이유

가우시안 $x \sim \mathcal{N}(0,\Sigma_0)$ 의 미분 엔트로피는
$h(x) = \tfrac12\log\big((2\pi e)^d \det\Sigma_0\big)$ 다. 측정 $y_S$ 를 받은 뒤의 사후분포도
가우시안이고 그 공분산은 **측정값과 무관하게** $\Sigma_S = \Lambda_S^{-1}$ 이다(선형 가우시안의
핵심). 따라서 $h(x\mid y_S) = \tfrac12\log\big((2\pi e)^d\det\Sigma_S\big)$ 이고

$$
I(x;y_S) = h(x) - h(x\mid y_S) = \tfrac12\log\frac{\det\Sigma_0}{\det\Sigma_S}
= \tfrac12\log\det(\Lambda_S\Sigma_0), \tag{4}
$$

여기서 $\Lambda_S = \Lambda_0 + \sum_{i\in S}A_i^\top R_i^{-1}A_i$ 를 넣으면 (1)이다.
$\log\det(\Lambda_S\Sigma_0) = \log\det\Lambda_S - \log\det\Lambda_0$ 이므로 둘은 같은 식이다.

**두 번째 등식의 의미.** $h(x\mid y_S)$ 에서 조건부 엔트로피는 보통 $y$ 에 대한 기댓값인데,
선형 가우시안에서는 **사후 공분산이 $y$ 에 의존하지 않으므로** 기댓값이 필요 없다. 그래서
(1)은 측정을 수행하기 **전에** 계산할 수 있고, 다음이 따라온다:

$$
\max_{\text{정책}} \mathbb{E}\big[I(x;y_{S(\pi)})\big] = \max_{\lvert S\rvert\le k} I(x;y_S)
\quad\Longrightarrow\quad \text{개루프 계획이 최적.} \tag{5}
$$

즉 "보고 나서 다음을 정하는" 적응적 정책이 아무 이득을 주지 않는다. 이것이
`atanasov2015-decentralized-active` 가 능동 정보 수집을 POMDP 가 아니라 **결정론적 최적 제어**로
바꿀 수 있는 근거다.

**가정이 깨지는 곳**: (5)는 ⓐ 측정 모형이 선형이고 ⓑ 잡음이 가우시안이며 ⓒ **어느 측정을
쓸 수 있는지가 상태에 의존하지 않을** 때만 성립한다. 거리 측정의 분산이 거리에 의존하거나
(측정 모형의 상태 의존), 가려짐(occlusion)이 상태에 의존하면 사후 공분산이 $y$ 에 의존하고
적응적 정책이 진짜로 더 좋아진다. 이것이 능동 지각이 일반적으로 어려운 이유다.

### R2 — submodularity 가 PSD 순서에서 나온다

**한계 이득의 닫힌 형태.** $S$ 를 받은 뒤 $j$ 를 더하면
$\Lambda_{S\cup j} = \Lambda_S + A_j^\top R_j^{-1}A_j$ 이므로

$$
\Delta_j(S) = \tfrac12\log\frac{\det\Lambda_{S\cup j}}{\det\Lambda_S}
= \tfrac12\log\det\!\left(I + \Sigma_S A_j^\top R_j^{-1}A_j\right)
= \tfrac12\log\det\!\left(I + R_j^{-1}A_j\Sigma_S A_j^\top\right), \tag{6}
$$

마지막 등식은 $\det(I+UV) = \det(I+VU)$ (Sylvester) 다. 중요한 점: (6)의 우변은 측정 차원
$\dim y_j$ 짜리 행렬식이므로 $d$ 가 커도 계산이 싸다.

**단조성.** $\Sigma_S \succeq 0$ 이므로 $R_j^{-1/2}A_j\Sigma_SA_j^\top R_j^{-1/2} \succeq 0$ 이고
$\det(I + \cdot) \ge 1$ 이므로 $\Delta_j(S) \ge 0$. 즉 **정보는 해롭지 않다.**

**submodularity.** $S \subseteq T$ 라 하자. 그러면
$\Lambda_T - \Lambda_S = \sum_{i\in T\setminus S}A_i^\top R_i^{-1}A_i \succeq 0$ 이므로
$\Lambda_S \preceq \Lambda_T$ 이고, 역의 PSD 역순성에서

$$
\Sigma_S = \Lambda_S^{-1} \;\succeq\; \Lambda_T^{-1} = \Sigma_T
\;\Longrightarrow\; A_j\Sigma_SA_j^\top \succeq A_j\Sigma_TA_j^\top
\;\Longrightarrow\; \Delta_j(S) \ge \Delta_j(T). \tag{7}
$$

마지막 함의는 $\log\det$ 가 PSD 순서에 대해 단조라는 사실이다($A \succeq B \succ 0
\Rightarrow \det A \ge \det B$). 이것이 submodularity 의 정의 그 자체다. $\square$

**세 줄짜리 증명의 의미.** submodularity 는 "수확 체감"이라는 조합적 성질로 소개되지만,
여기서는 **공분산이 정보를 받을수록 PSD 순서로 작아진다**는 추정 이론의 사실과 완전히 같다.
그래서 가정은 단 하나 — $\Lambda_T - \Lambda_S$ 가 PSD 여야 한다는 것, 즉 **측정들의 정보
기여가 더해져야 한다**는 것이다. 그것이 조건부 독립 가정이다.

**가정이 깨지는 곳**: 측정 잡음이 센서 사이에 **상관**되면 $\Lambda_{S}$ 가 더 이상
$\sum_i A_i^\top R_i^{-1}A_i$ 의 합이 아니고 $\Lambda_{S\cup j} - \Lambda_S$ 가 PSD 가 아닐 수
있다. 그러면 (7)이 무너진다 — R5 의 반례가 정확히 이것이다. 또 Krause 등이 다루는
**미관측 지점의 예측**을 목적으로 삼으면($I(\text{관측}; \text{미관측})$) 목적함수가 엄밀히는
submodular 가 아니고 이산화 조건 아래 **근사적으로만** submodular 다
(`krause2008-submodular` §3). 논문 제목의 "near-optimal"이 그 뜻이다.

### R3 — $(1-1/e)$ 의 증명

$S_i$ 를 탐욕이 $i$ 단계까지 고른 집합, $\mathrm{OPT}$ 를 최적해($\lvert\mathrm{OPT}\rvert = k$),
$\delta_i = f(\mathrm{OPT}) - f(S_i)$ 를 간극이라 하자.

**1단계 (덮기).** 단조성과 submodularity 에서

$$
f(\mathrm{OPT}) \;\le\; f(\mathrm{OPT}\cup S_i)
\;=\; f(S_i) + \sum_{o\in\mathrm{OPT}\setminus S_i}\Delta_o\big(S_i \cup \{\text{앞의 } o\text{들}\}\big)
\;\le\; f(S_i) + \sum_{o\in\mathrm{OPT}}\Delta_o(S_i). \tag{8}
$$

첫 부등식은 단조성, 가운데는 망원합(telescoping), 마지막은 submodularity ($S_i$ 에 원소를 더한
집합에서의 한계 이득 $\le$ $S_i$ 에서의 한계 이득)다.

**2단계 (탐욕의 선택).** 탐욕은 한계 이득이 최대인 원소를 고르므로 모든 $o$ 에 대해
$f(S_{i+1}) - f(S_i) \ge \Delta_o(S_i)$ 다. (8)의 합에 항이 $k$ 개이므로

$$
\delta_i = f(\mathrm{OPT}) - f(S_i) \;\le\; \sum_{o\in\mathrm{OPT}}\Delta_o(S_i)
\;\le\; k\big(f(S_{i+1}) - f(S_i)\big) = k(\delta_i - \delta_{i+1}). \tag{9}
$$

**3단계 (기하적 감소).** (9)를 정리하면 $\delta_{i+1} \le (1 - 1/k)\delta_i$ 이고,
$\delta_0 = f(\mathrm{OPT})$ 에서

$$
\delta_k \le \left(1-\tfrac1k\right)^{\!k} f(\mathrm{OPT})
\;\Longrightarrow\;
f(S_k) \ge \left(1-\left(1-\tfrac1k\right)^{\!k}\right)f(\mathrm{OPT})
\ge \left(1-\tfrac1e\right)f(\mathrm{OPT}). \tag{10}
$$

마지막 부등식은 $(1-1/k)^k \le e^{-1}$ 이다(모든 $k \ge 1$). $\square$

**어느 가정이 어디에 쓰였는가.** 단조성은 (8)의 첫 부등식에만, submodularity 는 (8)의 마지막
부등식에만, $f(\emptyset)=0$ 은 $\delta_0 = f(\mathrm{OPT})$ 에만 쓰였다. 그래서 세 가정 중
하나를 지우면 각각 다른 방식으로 깨진다(문제 P1).

**가정이 깨지는 곳**: (3)은 **기수 제약**($\lvert S\rvert\le k$)에 대한 것이다. 제약이 비용
예산(각 측정의 비용이 다름)이면 탐욕은 보장을 잃고 비용 대비 이득 탐욕 + 부분 열거가
$(1-1/e)$ 를 회복한다. 제약이 매트로이드면 단순 탐욕은 $1/2$ 만 주고 $(1-1/e)$ 는
continuous greedy 가 필요하다. 그리고 (10)은 $f$ 의 평가가 **정확**하다고 가정한다 — 표본으로
추정한 상호정보를 쓰면 보장에 추정 오차가 더해진다.

### R4 — 보장과 성능은 다른 것이다

(3)은 **모든** 단조 submodular 함수에 대한 최악의 경우다. 두 가지를 측정하면 그 차이가 보인다.

**가우시안 상호정보(이 문제군).** $d=4$, 후보 $m=16$, $k=4$, 무작위 50 사례에서 탐욕과
완전 탐색($\binom{16}{4} = 1820$ 가지)을 비교한 결과:

| 지표 | 값 |
|---|---|
| 탐욕/최적 평균 | $0.9941$ |
| 최소 | $0.9621$ |
| 최대 | $1.0000$ |
| 정확히 최적인 비율 | $0.600$ |
| (3)의 한계 | $0.6321$ |

**최대 피복의 타이트 족.** 고전적 구성(원소가 $k$ 개의 행과 $m$ 개의 열로 놓이고 열 $j$ 의
원소 무게가 $(1-1/k)^{j-1}$, 피복 집합은 각 행과 각 열, 예산 $k$)에서는 탐욕이 반드시 열을
먼저 고르고 비율이 $1-(1-1/k)^k$ 를 **달성**한다:

| $k$ | 탐욕/최적 (실측) | $1-(1-1/k)^k$ |
|---|---|---|
| 2 | $0.7500$ | $0.7500$ |
| 5 | $0.6724$ | $0.6723$ |
| 10 | $0.6515$ | $0.6513$ |
| 20 | $0.6417$ | $0.6415$ |

(실측이 셋째 자리에서 조금 큰 것은 유한한 열 개수 $m = 8k$ 때문에 최적해의 피복이 전체 무게에
$(1-1/k)^{m}$ 만큼 미달하기 때문이다.)

**읽는 법.** (3)은 **거짓이 아니고 느슨하다.** 느슨함의 원인은 한계가 함수 클래스 전체에 대한
것이고 타이트 족이 피복에서 오기 때문이다. 가우시안 상호정보는 그 족에 속하지 않는다 —
(6)의 로그 행렬식은 피복 함수보다 훨씬 "부드럽다". 그러므로 논문·보고서에서 ⓐ "탐욕이 최적의
63% 이상"이라고 쓰는 것은 맞지만 ⓑ "탐욕은 최적의 63% 정도를 낸다"고 쓰는 것은 틀렸다. 이
문제군에서는 99% 다. **[D2]**

### R5 — 상관 잡음이 submodularity 를 깨뜨린다

$x = (x_1,x_2)^\top \sim \mathcal{N}(0, I)$ 에 두 센서를 둔다:
$y_1 = x_1 + x_2 + n_1$, $y_2 = x_1 - x_2 + n_2$, 그리고

$$
\begin{pmatrix} n_1 \\ n_2\end{pmatrix} \sim
\mathcal{N}\!\left(0,\ \sigma^2\begin{pmatrix}1 & \rho \\ \rho & 1\end{pmatrix}\right),
\qquad \sigma = 0.3,\ \rho = 0.99. \tag{11}
$$

$f(S)$ 를 (1)로 계산할 때 **두 센서를 함께 쓰면 $R$ 의 역행렬이 $\rho$ 때문에 크게 증폭된다** —
$n_1 - n_2$ 의 분산이 $2\sigma^2(1-\rho) = 0.0018$ 로 거의 0 이므로 $y_1 - y_2 = 2x_2 + (n_1-n_2)$
가 $x_2$ 를 거의 완벽히 준다. 실측:

| 집합 | $f$ |
|---|---|
| $\{1\}$ | $1.5726$ |
| $\{2\}$ | $1.5726$ |
| $\{1,2\}$ | $5.1027$ |

따라서 $\Delta_2(\emptyset) = 1.5726$ 인데 $\Delta_2(\{1\}) = 5.1027 - 1.5726 = 3.5302$ 이다.
submodularity 는 $\Delta_2(\{1\}) \le \Delta_2(\emptyset)$ 을 요구하므로 **위반**이고
시너지가 $f(\{1,2\}) - f(\{1\}) - f(\{2\}) = +1.9576$ 이다.

**무엇이 깨졌는가.** R2 의 증명은 $\Lambda_{S\cup j} = \Lambda_S + A_j^\top R_j^{-1}A_j$ 에
의존했다. 잡음이 상관되면 $\Lambda_{\{1,2\}} \ne \Lambda_{\{1\}} + A_2^\top R_{22}^{-1}A_2$ 이고
정보 기여가 더해지지 않는다. 따라서 (7)이 성립하지 않는다.

**실무에서 언제 일어나는가.** ⓐ 공통 모드 오차 — 같은 클럭·같은 대기 지연·같은 캘리브레이션
오차를 공유하는 센서들(GNSS 다중 수신기, 같은 IMU 를 쓰는 다중 카메라). ⓑ 같은 장면을 보는
카메라들의 조명·날씨 상관. ⓒ 통신으로 받은 추정값들이 공통 조상을 가질 때
(`s5-comms-constrained-estimation` 의 주제). 이 경우 탐욕의 보장을 인용할 수 없고, 선택지는
상관을 모형에 넣어 $R$ 전체를 쓰거나(그러면 (6)이 집합에 의존해 계산이 비싸진다)
약submodular 지표($\kappa$-submodularity)로 열화된 보장을 쓰는 것이다. **[D2]**

**반대 방향도 정직하게 적는다**: 상관은 보장을 깨뜨리지만 **정보를 늘린다** — 위 예에서
$f(\{1,2\}) = 5.1027$ 은 독립 잡음일 때의 값보다 크다. 즉 상관 잡음은 "나쁜 것"이 아니고
**탐욕의 분석이 다루지 못하는 것**이다.

### R6 — 통신 한 라운드와 lazy 평가

**순차 vs 동시.** 로봇 2대가 각각 2개를 고른다. 두 방식이 있다.

- **순차(sequential greedy)**: 로봇 1이 2개를 고르고 그 결과를 보낸 뒤 로봇 2가 고른다. 이것은
  기수 제약 $k=4$ 에 대한 **중앙 탐욕과 같은 알고리즘**이므로 (3)이 그대로 적용된다.
- **동시(통신 없음)**: 둘이 각자 단독 이득 상위 2개를 고른다. 둘이 **같은 것**을 고르므로
  예산 4가 실제로는 2가 되고, 상수 배 보장이 없다.

실측(무작위 50 사례, $d=4$, $m=12$, 완전 탐색 대비):

| 방식 | 평균 | 최소 |
|---|---|---|
| 순차 탐욕 / 최적 | $0.9968$ | $0.9692$ |
| 동시(통신 없음) / 최적 | $0.5654$ | $0.4386$ |

동시 선택의 최소가 $0.4386$ 으로 **$1/2$ 아래**라는 점이 요점이다 — 상수 배 보장이 아예 없다.
즉 `atanasov2015-decentralized-active` 가 쓰는 **선택당 통신 한 라운드**(또는 순차 할당)가
바로 (3)을 사는 값이다.

**lazy 탐욕(CELF).** submodularity 는 공짜 가속도 준다: 이전 라운드에 계산한 $\Delta_j$ 는
현재 라운드의 $\Delta_j$ 에 대한 **상계**이므로(바로 (7)이다), 상계가 현재 최선보다 작으면
다시 계산할 필요가 없다. 실측($d=4$, $m=40$, $k=6$, 30 사례): 평가 횟수가
$225.0 \to 98.9$ ($2.28\times$ 감소)이고 선택은 30/30 **동일**하다. 보장은 같고 계산만 준다.

**가정이 깨지는 곳**: 순차 탐욕이 중앙 탐욕과 같아지는 것은 제약이 **공통 기수**일 때다.
각 로봇이 자기 후보 집합에서 고르는 **분할 매트로이드**면 순차 탐욕은 $1/2$ 만 보장한다.
그리고 lazy 탐욕의 상계는 submodularity 에 의존하므로 R5 의 상관 잡음에서는 **잘못된 선택**을
낼 수 있다(문제 P5). **[D2]**

## 증명 스케치

### R2' — 상호정보의 submodularity

**가설** H1: $x$ 와 모든 측정이 결합 가우시안이고 측정 모형이 선형이다. H2: 측정 잡음이 센서
사이에 **독립**이다(조건부 독립). H3: $\Lambda_0 \succ 0$.
**결론** C: $f(S) = I(x;y_S)$ 가 단조이고 submodular 이며 $f(\emptyset)=0$ 이다.

**전략**: 조합적 성질을 선형대수의 PSD 순서로 환원한다.

1. **닫힌 형태.** H1·H3 에서 (4)가 성립하고 $f(\emptyset)=0$ 이다.
2. **정보의 가법성.** H2 에서 $\Lambda_S = \Lambda_0 + \sum_{i\in S}A_i^\top R_i^{-1}A_i$ 이므로
   $S\subseteq T \Rightarrow \Lambda_T - \Lambda_S \succeq 0$.
3. **공분산의 역순.** $0 \prec \Lambda_S \preceq \Lambda_T \Rightarrow \Sigma_S \succeq \Sigma_T$
   (역행렬의 PSD 역순성).
4. **한계 이득의 단조성.** (6)에서 $\Delta_j(S) = \tfrac12\log\det(I+R_j^{-1}A_j\Sigma_SA_j^\top)$
   이고 3단계와 $\log\det$ 의 PSD 단조성에서 $\Delta_j(S)\ge\Delta_j(T)$. 또 $\Sigma_S\succeq0$ 에서
   $\Delta_j(S)\ge0$.
5. **결론.** 4단계가 submodularity 의 정의이고 단조성이다. C. $\square$

**가설을 지우면**: H2 를 지우면 2단계가 무너지고 (실제로) submodularity 가 거짓이 된다
(R5 의 반례). H1 의 선형성을 지우면 (4)가 성립하지 않고 $f$ 를 라플라스 근사로 계산해야 하며
submodularity 는 근사적으로만 남는다. H3 를 지우면($\Lambda_0$ 이 특이) 초기 $\log\det$ 가
$-\infty$ 라서 $f$ 가 정의되지 않는다 — 비관측 방향이 있다는 뜻이고, 그 방향을 떼어내고
다시 정의해야 한다.

### R3' — 탐욕의 $(1-1/e)$

**가설** H1: $f$ 가 단조. H2: $f$ 가 submodular. H3: $f(\emptyset)=0$. H4: 제약이 기수
$\lvert S\rvert \le k$. H5: $f$ 의 평가가 정확하다.
**결론** C: $f(S_k) \ge (1-(1-1/k)^k)f(\mathrm{OPT}) \ge (1-1/e)f(\mathrm{OPT})$.

**전략**: 간극 $\delta_i$ 가 매 단계 적어도 $1/k$ 배 줄어든다는 것을 보인다.

1. **덮기.** H1 로 $f(\mathrm{OPT}) \le f(\mathrm{OPT}\cup S_i)$, 망원합과 H2 로 (8).
2. **탐욕의 최대성.** 탐욕의 정의와 H5 로 모든 $o$ 에 대해 $\delta_i - \delta_{i+1} \ge \Delta_o(S_i)$.
3. **$k$ 개의 항.** H4 로 (8)의 합이 $k$ 개 항이므로 (9): $\delta_i \le k(\delta_i-\delta_{i+1})$.
4. **기하 감소.** $\delta_{i+1}\le(1-1/k)\delta_i$, H3 로 $\delta_0 = f(\mathrm{OPT})$, 따라서 (10).
5. **결론.** $(1-1/k)^k \le e^{-1}$. C. $\square$

**가설을 지우면**: H1 을 지우면 1단계가 깨진다(비단조 submodular 최대화는 상수 $1/2$ 이하의
다른 보장을 가지며 탐욕이 임의로 나쁠 수 있다). H2 를 지우면 1단계의 마지막 부등식이 깨져
보장이 사라진다(R5). H4 를 매트로이드로 바꾸면 3단계의 "항이 $k$ 개"가 무의미해지고 단순
탐욕은 $1/2$ 만 남는다. H5 를 지우면(표본 추정) 2단계가 오차만큼 느슨해지고 보장에
$-\epsilon$ 항이 붙는다.

## 문제 세트

해답 방침은 문제마다 적어 두었다. 난이도: ★ 15분 / ★★ 1시간 / ★★★ 하루 이상.

**P1 (증명, ★★, R3)** R3' 의 다섯 단계를 빠진 줄 없이 쓰고, 세 가설을 각각 지웠을 때 **어느
단계의 어느 부등식**이 깨지는지 짚으라: ⓐ 단조성 ⓑ submodularity ⓒ $f(\emptyset)=0$.
*전략 + 핵심 부등식*: ⓒ 가 함정이다 — $f(\emptyset) = c > 0$ 이면 $\delta_0 = f(\mathrm{OPT})$ 가
아니고 보장이 $f(S_k) - c \ge (1-1/e)(f(\mathrm{OPT})-c)$ 꼴로 바뀐다. 즉 상수항을 빼면
보장이 되살아난다. 전개는 숨긴다.

**P2 (증명, ★★, R2)** (6)의 마지막 등식($\det(I+UV)=\det(I+VU)$)을 증명하고, 그것이 왜 계산을
싸게 만드는지 차원으로 설명하라. 그 다음 ⓐ $\log\det$ 의 PSD 단조성을 증명하고
ⓑ 역행렬의 PSD 역순성($0\prec A\preceq B \Rightarrow A^{-1}\succeq B^{-1}$)을 증명하라.
*전략*: 블록 행렬 $\begin{pmatrix}I & -U\\ V& I\end{pmatrix}$ 의 행렬식을 두 방향으로 전개한다.
ⓑ 는 $B^{-1/2}AB^{-1/2} \preceq I$ 로 바꿔 고유값으로 논증한다. 전개는 숨긴다.

**P3 (유도, ★★, R1)** (5)를 정확히 진술하고 증명하라. 그 다음 ⓐ 측정의 가용성이 상태에
의존하는 경우(가려짐) ⓑ 잡음 분산이 상태에 의존하는 경우(거리에 비례하는 거리 측정 분산)에
대해 반례의 구조를 각각 하나씩 설계하라 — 적응적 정책이 개루프보다 **엄격히** 나은 사례여야
한다.
*해답 스케치*: ⓑ 가 쉽다 — 표적이 둘 중 하나에 있고 가까운 쪽을 재면 분산이 작은 설정에서,
첫 측정이 어느 쪽인지 알려 주면 둘째 측정을 그쪽으로 보낼 수 있다. 개루프는 그럴 수 없다.
"엄격히"를 보이려면 두 정책의 기대 상호정보를 직접 계산해야 한다.

**P4 (계산, ★, R4·R5·R6)** 재현 과제에서 ⓐ 탐욕/최적의 평균·최소·정확히 최적인 비율,
ⓑ submodularity 위반 횟수, ⓒ 상관 잡음 반례의 세 값과 시너지, ⓓ 피복 타이트 족의 비율,
ⓔ 순차·동시 비율, ⓕ lazy 탐욕의 평가 횟수를 구하라.
*정답*: ⓐ $0.9941 / 0.9621 / 0.600$. ⓑ 4000 시행 중 0. ⓒ $1.5726, 1.5726, 5.1027$, 시너지
$+1.9576$. ⓓ $0.7500, 0.6724, 0.6515, 0.6417$. ⓔ $0.9968$(최소 $0.9692$) / $0.5654$(최소
$0.4386$). ⓕ $225.0 \to 98.9$, $2.28\times$, 선택 30/30 동일. 허용오차: 평균값 상대오차 2%,
피복 비율은 소수 셋째 자리까지.
검산: ⓐ 의 비율이 **1을 넘으면** 완전 탐색이 틀렸다(탐욕해도 탐색 공간 안에 있다).
ⓑ 가 0이 아니면 정보행렬을 더하는 대신 공분산을 더했을 가능성이 크다.

**P5 (구현, ★★★, R2·R3·R6)** 탐욕·lazy 탐욕·완전 탐색을 구현하라.
*루브릭*: ⓐ (1)을 **정보 형태**로 계산(공분산 역행렬을 매번 만들지 않음) ⓑ `slogdet` 로
수치 안정성 확보 ⓒ lazy 탐욕이 평탐욕과 **같은 집합**을 반환함을 30/30 확인 ⓓ R5 의 상관 잡음
설정에서 lazy 탐욕이 평탐욕과 **다른** 답을 낼 수 있음을 보이거나, 왜 이 특정 사례에서는
같은지 설명 ⓔ 완전 탐색의 조합 수를 보고하고 $\binom{m}{k}$ 와 일치 확인.

**P6 (반례, ★★, R4·R5)** ⓐ "$(1-1/e)$ 가 탐욕의 기대 성능이다"가 거짓임을 두 실측 표로 보이고,
ⓑ 가우시안 상호정보에서 비율을 $0.9621$ 보다 낮추는 사례를 찾아 보고, 못 찾으면 **찾지 못했다고
쓰고** 어디까지 탐색했는지 적으라. ⓒ 상관계수 $\rho$ 를 $0$ 에서 $0.999$ 까지 바꾸며
시너지가 언제 양수가 되는지 측정하라.
*성질 체크리스트*: ⓐ 는 **두** 표를 모두 인용해야 통과 — 가우시안만 보이면 "한계가 틀렸다"로
오독될 수 있고, 피복 표가 한계가 **타이트함**을 보여야 한다. ⓑ 에서 못 찾았다고 쓰는 것은
감점이 아니다. ⓒ 의 전이점은 $\rho$ 뿐 아니라 $\sigma$ 와 $A$ 에도 의존하므로 한 축만 바꾸면
미달이다.

**P7 (논문, ★★, R2·R6)** `krause2008-submodular` 3-5절과
`atanasov2015-decentralized-active` III-V 절을 읽고 ⓐ 두 논문의 목적함수가 **서로 다름**을
식으로 구분하고(미관측 지점의 예측 vs 상태의 상호정보), ⓑ Krause 등의 "near-optimal"이
본문 R2 의 어느 가정과 관련되는지 쓰고, ⓒ Atanasov 등이 개루프로 갈 수 있는 근거가 본문 (5)와
같은지 확인하라.
*루브릭*: ⓐ 를 구분하면 통과. ⓑ 가 핵심 — GP 에서 미관측 지점 예측의 상호정보는 엄밀히
submodular 가 아니고 이산화 조건 아래 $\epsilon$ 만큼 열화된 보장을 얻는다는 것을 짚어야 한다.
ⓒ 에서 선형 가우시안 가정의 역할을 지적하면 우수.

## 재현 과제

**티어 R2 (알고리즘 재구현).** 계산 예산: 노트북 CPU 1코어, 전체 3분 이내, 메모리 300MB 이하.
numpy 와 표준 라이브러리(`heapq`, `itertools`)만 쓴다.

**입력 데이터**는 아래 생성기가 만든다(고정 시드·결정론적). 외부 데이터셋이 필요 없다.
**학습자가 쓸 것은 상호정보 평가, 탐욕, lazy 탐욕, 완전 탐색 네 함수**다.

```python
"""s5-active-information-gathering 재현 과제: 생성기와 상호정보 평가."""

import numpy as np

SEED = 20261113


def mi_gain(prior_inf, blocks, subset):
    """f(S) = 0.5 * (logdet(Lambda_0 + sum_i blocks[i]) - logdet(Lambda_0))."""
    inf = prior_inf.copy()
    for i in subset:
        inf = inf + blocks[i]
    s0, ld0 = np.linalg.slogdet(prior_inf)
    s1, ld1 = np.linalg.slogdet(inf)
    assert s0 > 0 and s1 > 0
    return 0.5 * (ld1 - ld0)


def make_instance(d, m, rng, noise=0.5):
    """사전 정보행렬 I 와, 무작위 방향을 1차원으로 재는 후보 m 개의 정보 기여."""
    prior_inf = np.eye(d) * 1.0
    blocks = []
    for _ in range(m):
        a = rng.normal(size=(1, d))
        blocks.append(a.T @ a / noise**2)
    return prior_inf, blocks


def coverage_weights(k, m=None):
    """최대 피복의 타이트 족: 열 j 의 원소 무게가 (1-1/k)^j, 행 k 개 · 열 m 개."""
    m = 8 * k if m is None else m
    return np.array([(1 - 1 / k) ** j for j in range(m)])
```

**규약(반드시 맞출 것).** ⓐ $f$ 는 **정보 형태**로 계산한다(공분산을 만들어 더하지 않는다).
ⓑ 행렬식은 `np.linalg.slogdet` 로 계산한다(`det` 는 언더플로한다). ⓒ 설정마다
`np.random.default_rng(SEED)` 를 **새로** 만든다. ⓓ 피복 족에서 탐욕은 한계 이득 동점일 때
**열**을 고른다(구성이 그렇게 설계되어 있고, 열 무게가 행 무게보다 $k(1-1/k)^m$ 만큼 엄격히
크다). ⓔ lazy 탐욕은 상계를 힙에 넣고, 꺼낸 항목을 재계산한 값이 힙의 다음 상계 이상일 때만
확정한다.

**Part A — 탐욕 vs 완전 탐색.** $d=4$, $m=16$, $k=4$, 50 사례. 탐욕/최적의 평균·최소·최대와
정확히 최적인 비율을 보고한다. 완전 탐색의 조합 수도 보고한다.

**Part B — submodularity 확인.** $d=3$, $m=8$ 사례 200개에 대해 각 20회, $A\subset B$ 와
$i \notin B$ 를 무작위로 뽑아 $\Delta_i(A) - \Delta_i(B) \ge 0$ 을 확인한다. 위반 횟수와
최소값을 보고한다.

**Part C — 상관 잡음 반례.** (11)의 설정($\sigma=0.3$, $\rho=0.99$, $A_1 = [1\ 1]$,
$A_2 = [1\ -1]$)에서 $f(\{1\}), f(\{2\}), f(\{1,2\})$ 와 시너지를 보고한다. 여기서는
$R$ 전체를 써야 하므로 $\Lambda_S = \Lambda_0 + A_S^\top R_{SS}^{-1} A_S$ 로 계산한다.

**Part D — 순차 vs 동시.** $d=4$, $m=12$, 로봇 2대 × 2개, 50 사례. 순차 탐욕(= 중앙 탐욕
$k=4$)과 동시 선택(각 로봇이 단독 이득 상위 2개를 고름 → 같은 집합이 되어 유효 크기 2)을
완전 탐색($k=4$) 대비 비율로 보고한다.

**Part E — 피복 타이트 족.** $k = 2, 5, 10, 20$ 에 대해 탐욕/최적과 $1-(1-1/k)^k$ 를 비교한다.

**Part F — lazy 탐욕.** $d=4$, $m=40$, $k=6$, 30 사례. 평탐욕과 lazy 탐욕의 **상호정보 평가
횟수**와 선택 일치 여부를 보고한다.

**수용 기준 — 여섯 조건을 모두 만족해야 통과다.**

1. **Part A** — 탐욕/최적 평균 $0.9941$, 최소 $0.9621$, 최대 $1.0000$, 정확히 최적 비율
   $0.600$ (평균 상대오차 2%, 비율 $\pm0.08$). 완전 탐색 조합 수가
   $\binom{16}{4} = 1820$ 이다. 이 값들이 한계 $0.6321$ 보다 **훨씬 높음**을 명시한다.
2. **Part B** — 4000 시행에서 위반 **0건**이고 $\min(\Delta_i(A)-\Delta_i(B)) > 0$
   (실측 $5.129\times10^{-5}$). 위반이 하나라도 나오면 정보행렬 누적이 틀렸다.
3. **Part C** — $f(\{1\}) = f(\{2\}) = 1.5726$, $f(\{1,2\}) = 5.1027$ (절대오차 $10^{-3}$),
   따라서 $\Delta_2(\{1\}) = 3.5302 > \Delta_2(\emptyset) = 1.5726$ 이고 시너지가
   $+1.9576$ 이다. **submodularity 위반을 명시적으로 출력**한다.
4. **Part D** — 순차/최적 평균 $0.9968$(최소 $0.9692$), 동시/최적 평균 $0.5654$(최소
   $0.4386$). 동시의 **최소가 $1/2$ 아래**임을 명시한다.
5. **Part E** — 비율이 $k=2,5,10,20$ 에 대해 $0.7500, 0.6724, 0.6515, 0.6417$ 이고
   $1-(1-1/k)^k$ 와 소수 셋째 자리까지 일치한다. 탐욕의 첫 선택이 네 경우 모두 **열**이다.
6. **Part F** — 평탐욕 평가 $225.0$, lazy 평가 $98.9$ ($2.28\times$), 선택 일치 **30/30**.
   평탐욕의 평가 횟수는 $\sum_{i=0}^{5}(40-i) = 225$ 로 **정확히** 맞아야 한다.

**비교 대상**: ⓐ Part A·D 의 베이스라인은 완전 탐색(최적)이다. ⓑ Part E 의 베이스라인은
해석적 값 $1-(1-1/k)^k$ 다. ⓒ Part F 의 베이스라인은 평탐욕의 평가 횟수. 선택: Part C 에서
$\rho$ 를 $0 \to 0.999$ 로 쓸면서 시너지의 부호가 바뀌는 지점을 찾으면 문제 P6ⓒ 가 해결된다.

**보고할 수치**: 위 여섯 조건의 모든 값, 그리고 Part A 에서 탐욕이 최적과 다른 20개 사례의
비율 분포(최소·중위수).

**실패 진단표**

| 증상 | 원인 | 확인 방법 |
|---|---|---|
| Part A 의 비율이 1 을 넘는다 | 완전 탐색이 탐욕과 다른 목적함수를 쓴다(또는 조합을 빠뜨렸다) | 조합 수가 $\binom{16}{4}=1820$ 인지, 두 함수가 같은 `mi_gain` 을 쓰는지 확인 |
| Part B 에서 위반이 나온다 | 정보행렬 대신 공분산을 더했다 | $\Lambda_S = \Lambda_0 + \sum A^\top R^{-1}A$ 인지 확인. 공분산은 더해지지 않는다 |
| Part B 의 최소값이 정확히 0 이다 | $A \subset B$ 가 아니라 $A = B$ 를 뽑았다 | 두 집합의 크기가 다르고 포함 관계인지 확인 |
| Part C 에서 시너지가 0 이다 | 두 센서를 따로 더해 $R$ 의 비대각을 무시했다 | $\Lambda_{\{1,2\}}$ 를 $2\times2$ 전체 $R$ 의 역행렬로 계산하는지 확인 |
| Part C 에서 $f$ 가 발산한다 | $\rho \to 1$ 에서 $R$ 이 특이에 가깝다 | $\rho = 0.99$ 를 쓰고 `slogdet` 로 계산. $\rho = 1$ 은 정의되지 않는다 |
| Part E 의 비율이 $1.0$ 이다 | 동점에서 탐욕이 **행**을 골랐다 | 열 무게 $k\cdot w_1 = k$ 와 행 무게 $\sum_j w_j < k$ 를 직접 출력해 비교 |
| Part E 의 비율이 셋째 자리에서 어긋난다 | 열 개수 $m$ 이 작아 최적해가 전체 무게에 미달한다 | $m = 8k$ 이상인지 확인. $m=60$ 고정은 $k=20$ 에서 0.4% 어긋난다 |
| Part F 의 평탐욕 평가가 225 가 아니다 | 이미 고른 후보를 다시 평가했다 | $\sum_{i=0}^{k-1}(m-i)$ 와 비교 |
| Part F 의 선택이 다르다 | lazy 의 확정 조건이 틀렸다(상계와 비교하지 않고 바로 확정) | 재계산한 이득이 힙의 다음 상계 이상일 때만 확정하는지 확인 |

## 열린 문제

- **(열린 문제) 상관 잡음 아래의 보장** — R5 는 센서 잡음이 상관되면 submodularity 가 깨지고
  (3)이 사라짐을 보인다. 약submodularity($\kappa$-submodularity, submodularity ratio)로
  열화된 보장을 쓸 수 있지만, **실제 센서 네트워크의 상관 구조에서 그 상수를 계산하거나
  유용하게 하한하는 방법**이 없다. 현재 접근: 상관을 모형에 넣고 집합마다 전체 $R$ 을 역행렬
  하는 비싼 정확 계산. 비어 있는 자리: 공통 모드 잡음의 구조(랭크·크기)에서 submodularity
  ratio 로 가는 하한.
- **(열린 문제) 보장과 성능의 간극을 설명하는 이론** — R4 는 가우시안 상호정보에서 탐욕이
  평균 $0.9941$, 최소 $0.9621$ 인데 보장은 $0.6321$ 임을 보인다. 이 36%p 간극을 설명하는
  **문제군 특유의** 분석(곡률 $\kappa$, 로그 행렬식의 매끄러움, 랜덤 설계의 집중 현상)이
  부분적으로만 있다. 현재 접근: 곡률 기반 보장 $\tfrac1\kappa(1-e^{-\kappa})$. 비어 있는 자리:
  무작위 선형 가우시안 설계에서 탐욕의 비율에 대한 고확률 하한.
- **(열린 문제) 비선형·상태 의존 측정의 적응성 이득** — (5)는 선형 가우시안에서 개루프가
  최적임을 말하지만, 가려짐·거리 의존 잡음처럼 **측정 모형이 상태에 의존**하면 적응적 정책이
  엄격히 낫다. 그 이득의 크기를 문제의 구조에서 미리 **한계지을** 방법이 알려져 있지 않다 —
  즉 "이 문제에서 폐루프로 갈 가치가 있는가"를 계획 전에 답할 수 없다. 현재 접근: 적응
  submodularity(adaptive submodularity)가 특정 구조에서 $(1-1/e)$ 를 회복한다. 비어 있는 자리:
  적응성 간극(adaptivity gap)의 문제 구조 의존 상한.
