# 통신 제약과 분산 추정

## 전제와 기호

`c5-observability-consistency` 의 일관성(consistency) 정의와 NEES 를 그대로 쓰고,
`s5-distributed-optimization` 에서 로봇들이 **원자료 대신 요약**(추정값과 공분산)을 주고받는다는
설정을 이어받는다. 이 레슨의 질문은 하나다 — **통신으로 받은 요약을 융합할 때, 보고하는 공분산이
언제 거짓말을 하는가.** 권장 선수는 위 두 레슨이다.

| 기호 | 뜻 |
|---|---|
| $x \in \mathbb{R}^d$ | 추정 대상. 사전분포 $x \sim \mathcal{N}(x_0, P_0)$, $\Lambda_0 = P_0^{-1}$ |
| $(a, P_a)$, $(b, P_b)$ | 두 노드의 추정값과 **보고** 공분산 |
| $e_a = a - x$ | 추정 오차. $\tilde{P}_a = \mathbb{E}[e_ae_a^\top]$ 가 **실제** 평균제곱오차 |
| $P_{ab} = \mathbb{E}[e_ae_b^\top]$ | 교차공분산. 통신으로는 보통 **전달되지 않는다** |
| 일관성 | $P \succeq \tilde{P}$ — 보고 공분산이 실제 오차보다 작지 않다 |
| NEES | $e^\top P^{-1} e$. 일관적이고 딱 맞으면 $\mathbb{E}[\mathrm{NEES}] = d$, 과확신이면 $> d$ |
| $\omega \in [0,1]$ | 공분산 교차(CI)의 가중치 |
| $\gamma$ | 측정 패킷의 도착 확률(독립 베르누이) |
| $a,\ q,\ r$ | 스칼라 계 $x_{k+1} = a x_k + w_k$, $y_k = x_k + v_k$ 의 계수와 잡음 분산 |

**세 가지 통신 결함**이 이 레슨의 지도다.

| 결함 | 무엇이 깨지는가 | 결과 | 다루는 곳 |
|---|---|---|---|
| 출처를 모르는 요약 | 독립 가정 | 과확신 (NEES $> d$) | R1·R2, 해법은 R3 |
| 패킷 손실 | 매 스텝 갱신 | 공분산의 기댓값이 발산할 수 있다 | R4 |
| 지연 | 측정 시각 = 현재 | 과확신, 지연에 선형 | R5 |

## 핵심 결과

괄호 안은 유도 깊이 등급이다(D0 인용 / D1 골격 / D2 완전 유도 / D3 증명 —
`f0-how-to-read-this-track` 레슨의 "유도 깊이 등급" 절).

- **R1 (공통 정보를 무시한 융합은 과확신이다) [D3]** — 두 노드가 같은 사전정보 $\Lambda_0$ 에서
  출발해 서로 독립인 측정으로 갱신했다면 오차의 교차공분산은
  $$
  P_{ab} = P_a\,\Lambda_0\,P_b \tag{1}
  $$
  이고, 이를 무시한 독립 가정 융합 $P_n = (P_a^{-1} + P_b^{-1})^{-1}$ 의 **실제** 공분산은
  $$
  \tilde{P}_n = P_n + 2\,P_n\Lambda_0P_n \;\succ\; P_n,
  \qquad \mathbb{E}[\mathrm{NEES}] = d + 2\operatorname{tr}(\Lambda_0P_n) \tag{2}
  $$
  이다. 즉 **항상 과확신**이고 그 크기가 닫힌 형태다. 정확한 해법은 공통 정보를 한 번 빼는
  것이다: $P_c^{-1} = P_a^{-1} + P_b^{-1} - \Lambda_0$ (채널 필터). 재현 과제 실측:
  $d = 3$ 에서 NEES 가 $4.156$ (예측 $4.149$), 채널 필터는 $3.004$.
- **R2 (소문 전파: 교환할 때마다 NEES 가 두 배) [D2]** — 융합한 추정을 다시 주고받아 또
  독립으로 융합하면 추정값은 그대로인데 보고 공분산만 $P_n/2^n$ 으로 줄어든다. 실제 오차는
  변하지 않으므로 NEES 가 $2^n$ 배가 된다. 실측: $4.156 \to 8.312 \to 16.625 \to 33.250 \to 66.499$.
- **R3 (공분산 교차는 어떤 상관에서도 일관적이다) [D2]** — $P_a \succeq \tilde{P}_a$,
  $P_b \succeq \tilde{P}_b$ 이면 **$P_{ab}$ 가 무엇이든**
  $$
  P_{\mathrm{CI}}^{-1} = \omega P_a^{-1} + (1-\omega)P_b^{-1}, \qquad
  c = P_{\mathrm{CI}}\big(\omega P_a^{-1}a + (1-\omega)P_b^{-1}b\big) \tag{3}
  $$
  가 $P_{\mathrm{CI}} \succeq \tilde{P}_c$ 를 만족한다. 증명은 볼록성 한 줄이고, 그 **여유**가
  정확히 $\omega(1-\omega)\,P_{\mathrm{CI}}\,\mathbb{E}[(p-q)(p-q)^\top]P_{\mathrm{CI}}$
  ($p = P_a^{-1}e_a$, $q = P_b^{-1}e_b$)다. 대가는 보수성이다 — 분산이 같은 스칼라에서
  $\mathbb{E}[\mathrm{NEES}] = (1+\rho)/2$ 로, 독립($\rho = 0$)이면 정보의 절반을 버린다.
- **R4 (패킷 손실의 임계 도착 확률) [D2]** — 불안정한 스칼라 계($\lvert a\rvert > 1$)에서
  측정이 확률 $\gamma$ 로만 도착하면 예측 공분산의 기댓값이
  $$
  \gamma > \gamma_c = 1 - \frac{1}{a^2} \tag{4}
  $$
  일 때만 유계다. 유계인 영역에서는 $S \le \mathbb{E}[P_k] \le V$ 로 끼워지고
  ($S$ 는 선형 하한의 고정점, $V$ 는 수정 Riccati 의 고정점), 분산까지 유한하려면 더 강한
  $\gamma > 1 - 1/a^4$ 이 필요하다. $a = 1.2$ 에서 $\gamma_c = 0.3056$ 이고, $\gamma = 0.2$ 의
  실측은 **중위수 $10.5$ 에 평균 수천~수만**이다 — 발산하는 것은 전형적 궤적이 아니라 꼬리다.
- **R5 (지연된 측정을 최신으로 쓰면 NEES 가 지연에 선형) [D2]** — 랜덤워크에서 $d$ 스텝
  지연된 측정을 현재 측정처럼 쓰면 필터는 **$d$ 스텝 전 상태**의 올바른 추정기가 되고
  $$
  \mathbb{E}[\mathrm{NEES}] = 1 + \frac{d\,q}{P_\infty},
  \qquad P_\infty = \tfrac12\big(-q + \sqrt{q^2 + 4qr}\big) \tag{5}
  $$
  이다. $q = 0.2$, $r = 0.5$ 에서 $d = 1, 2, 4, 8$ 의 예측 $1.863, 2.727, 4.453, 7.907$ 에
  실측 $1.857, 2.718, 4.434, 7.866$. 고치는 법은 예측 한 번이다 — 보고 공분산에 $dq$ 를 더한다.

## 유도

### R1 — 교차공분산과 과확신의 닫힌 형태

**설정.** 두 노드가 같은 사전정보 $(x_0, P_0)$ 를 갖고 각자 측정한다:
$y_a = H_ax + n_a$, $y_b = H_bx + n_b$, $n_a \sim \mathcal{N}(0,R_a)$, $n_b \sim \mathcal{N}(0,R_b)$
이고 $n_a$, $n_b$, 사전 오차 $e_0 = x_0 - x$ 는 서로 독립이다. 정보 형태의 갱신은

$$
P_a^{-1} = \Lambda_0 + H_a^\top R_a^{-1}H_a, \qquad
a = P_a\big(\Lambda_0x_0 + H_a^\top R_a^{-1}y_a\big), \tag{6}
$$

이고 $b$ 도 같다.

**오차를 원천으로 분해한다.** (6)에 $x_0 = x + e_0$, $y_a = H_ax + n_a$ 를 넣으면

$$
a = P_a\big[(\Lambda_0 + H_a^\top R_a^{-1}H_a)x + \Lambda_0e_0 + H_a^\top R_a^{-1}n_a\big]
  = x + P_a\big(\Lambda_0e_0 + H_a^\top R_a^{-1}n_a\big),
$$

즉

$$
e_a = P_a\Lambda_0e_0 + P_aH_a^\top R_a^{-1}n_a, \qquad
e_b = P_b\Lambda_0e_0 + P_bH_b^\top R_b^{-1}n_b. \tag{7}
$$

**두 오차가 $e_0$ 를 공유한다.** $n_a \perp n_b$ 이고 $\mathbb{E}[e_0e_0^\top] = P_0$ 이므로

$$
P_{ab} = \mathbb{E}[e_ae_b^\top] = P_a\Lambda_0\,P_0\,\Lambda_0P_b = P_a\Lambda_0P_b,
$$

즉 (1)이다. **교차공분산은 0 이 아니고, 사전정보가 강할수록(= $\Lambda_0$ 가 클수록) 크다.**

**독립 가정 융합의 실제 공분산.** 독립이라고 믿고 융합하면
$c = P_n(P_a^{-1}a + P_b^{-1}b)$, $P_n^{-1} = P_a^{-1} + P_b^{-1}$ 이고 오차는
$e_c = P_n(P_a^{-1}e_a + P_b^{-1}e_b)$ 다. 그 공분산은

$$
\begin{aligned}
\tilde{P}_n &= P_n\big[P_a^{-1}P_aP_a^{-1} + P_b^{-1}P_bP_b^{-1}
   + P_a^{-1}P_{ab}P_b^{-1} + P_b^{-1}P_{ab}^\top P_a^{-1}\big]P_n \\
 &= P_n\big[P_a^{-1} + P_b^{-1} + 2\Lambda_0\big]P_n
  = P_n + 2P_n\Lambda_0P_n,
\end{aligned}
$$

둘째 줄에서 (1)로 $P_a^{-1}P_{ab}P_b^{-1} = \Lambda_0$ 를 썼다. 이것이 (2)의 첫 식이고,
$\mathbb{E}[\mathrm{NEES}] = \operatorname{tr}(P_n^{-1}\tilde{P}_n) = d + 2\operatorname{tr}(\Lambda_0P_n)$
이 따라온다.

**읽는 법.** $P_n^{-1} = 2\Lambda_0 + (\text{측정 정보})$ 에 사전정보가 **두 번** 들어 있다.
(2)의 $2P_n\Lambda_0P_n$ 가 그 이중 계산의 값이다. 올바른 융합은 한 번을 빼는 것이다:

$$
P_c^{-1} = P_a^{-1} + P_b^{-1} - \Lambda_0, \qquad
c^\star = P_c\big(P_a^{-1}a + P_b^{-1}b - \Lambda_0x_0\big). \tag{8}
$$

(8)은 두 측정을 한 곳에 모아 갱신한 중앙집중 해와 **같다**(문제 P1). 이것을 통신 링크마다
"상대와 공유한 정보"를 기록해 두고 빼는 방식으로 구현한 것이 채널 필터다
(`grime1994-decentralized-data-fusion`).

**수치.** $P_0 = \operatorname{diag}(4, 1, 0.25)$, 노드 $a$ 가 $x_1, x_2$ 를 분산 $0.5, 0.5$ 로,
노드 $b$ 가 $x_2, x_3$ 을 분산 $0.5, 0.2$ 로 잰다. 표본 $4\times10^5$ 의 실측:

| 추정기 | 보고 $\operatorname{tr}P$ | 실제 $\operatorname{tr}\tilde{P}$ | NEES ($d = 3$) | $\lambda_{\min}(P - \tilde{P})$ |
|---|---|---|---|---|
| 노드 $a$ 단독 | $1.0278$ | $1.0294$ | $3.004$ | $-0.002$ |
| 독립 가정 융합 | $0.6436$ | $0.8283$ | $4.156$ | $-0.081$ |
| 채널 필터 (8) | $0.7556$ | $0.7567$ | $3.004$ | $-0.002$ |
| CI ($\omega = 0.837$) | $1.0608$ | $0.8987$ | $2.539$ | $+0.030$ |

(2)의 예측은 $\operatorname{tr}\tilde{P}_n = 0.8265$, $\mathbb{E}[\mathrm{NEES}] = 3 + 2\times0.5744 = 4.149$
이다. **두 가지를 읽는다.** ⓐ 독립 가정 융합의 **점 추정**은 나쁘지 않다(실제 $0.8283$ 은 단독
$1.0294$ 보다 좋다). 거짓말을 하는 것은 **공분산**이다($0.6436$ 이라고 보고한다). ⓑ 그 거짓말은
다음 단계에서 비용이 된다 — 과확신한 추정은 이후의 측정을 덜 믿고, 이상치 기각 게이트를 잘못
닫고, R2 처럼 다시 융합되면 기하급수로 나빠진다.

**가정이 깨지는 곳**: (1)은 두 노드가 **같은** 사전정보에서 출발하고 그 뒤의 측정이 독립일 때의
식이다. 공통 정보가 사전분포가 아니라 **공통 과정 잡음**이면(두 노드가 같은 움직이는 표적을
추적) 교차공분산이 시간에 따라 재귀적으로 쌓이고 닫힌 형태 (1)이 성립하지 않는다 — 그때는
교차공분산을 직접 전파하거나 R3 의 CI 로 간다. 또 (8)의 뺄셈은 "무엇을 공유했는지"를 **아는**
경우에만 가능하다. 통신 그래프에 **사이클**이 있으면 같은 정보가 여러 경로로 돌아와 링크별
기록만으로는 공통 정보를 식별할 수 없다(채널 필터는 트리에서만 정확하다).

### R2 — 소문 전파

R1 의 융합을 두 노드가 **둘 다** 수행했다고 하자. 이제 둘은 같은 $(c, P_n)$ 을 갖는다. 새
측정 없이 한 번 더 주고받아 독립으로 융합하면

$$
c' = \big(P_n^{-1} + P_n^{-1}\big)^{-1}\big(P_n^{-1}c + P_n^{-1}c\big) = c, \qquad
P' = \big(2P_n^{-1}\big)^{-1} = \tfrac12P_n.
$$

**추정값은 그대로인데 공분산만 반이 된다.** $n$ 번 반복하면 $P^{(n)} = P_n/2^n$ 이고, 실제
오차 $\tilde{P}_n$ 은 변하지 않으므로

$$
\mathbb{E}[\mathrm{NEES}^{(n)}] = \operatorname{tr}\big((P_n/2^n)^{-1}\tilde{P}_n\big)
 = 2^n\big(d + 2\operatorname{tr}(\Lambda_0P_n)\big). \tag{9}
$$

실측이 $4.156, 8.312, 16.625, 33.250, 66.499$ 로 (9)와 일치한다. 이것이 **소문 전파**(rumor
propagation, data incest)다 — 같은 소문을 여러 사람에게서 들으면 더 믿게 되는 것과 같은 오류이고,
두 오차의 상관계수가 정확히 1 인 극단이다(같은 추정값이므로).

**가정이 깨지는 곳**: (9)의 깔끔한 $2^n$ 은 교환 사이에 새 측정이 **없을** 때다. 새 측정이
들어오면 이중 계산된 정보와 새 정보가 섞여 배율이 $2^n$ 보다 작아지지만, 과확신 자체는
사라지지 않고 **필터가 새 측정을 덜 믿게 되어** 실제 오차까지 나빠진다(문제 P6). 그리고 로봇이
3대 이상이고 통신 그래프에 사이클이 있으면 한 로봇이 직접 다시 받지 않아도 같은 일이 일어난다.

### R3 — 공분산 교차의 일관성

교차공분산을 **모를** 때 쓸 수 있는 융합을 만든다. (3)의 오차는

$$
e_c = P_{\mathrm{CI}}\big(\omega P_a^{-1}e_a + (1-\omega)P_b^{-1}e_b\big)
    = P_{\mathrm{CI}}\big(\omega p + (1-\omega)q\big),
\qquad p := P_a^{-1}e_a,\; q := P_b^{-1}e_b.
$$

**볼록성 한 줄.** 임의의 벡터 $p, q$ 와 $\omega\in[0,1]$ 에 대해 다음 항등식이 성립한다(전개해
확인하라 — 문제 P2):

$$
\omega\,pp^\top + (1-\omega)\,qq^\top - \big(\omega p + (1-\omega)q\big)\big(\omega p + (1-\omega)q\big)^\top
 = \omega(1-\omega)\,(p-q)(p-q)^\top \;\succeq\; 0. \tag{10}
$$

기댓값을 취하면

$$
\mathbb{E}\big[(\omega p + (1-\omega)q)(\cdot)^\top\big]
 \;\preceq\; \omega\,\mathbb{E}[pp^\top] + (1-\omega)\,\mathbb{E}[qq^\top]. \tag{11}
$$

**입력의 일관성을 쓴다.** $\mathbb{E}[pp^\top] = P_a^{-1}\tilde{P}_aP_a^{-1} \preceq P_a^{-1}P_aP_a^{-1} = P_a^{-1}$
($\tilde{P}_a \preceq P_a$ 에 양변을 $P_a^{-1}$ 로 합동변환). $q$ 도 같다. 그러므로 (11)의 우변은
$\omega P_a^{-1} + (1-\omega)P_b^{-1} = P_{\mathrm{CI}}^{-1}$ 이하이고,

$$
\tilde{P}_c = P_{\mathrm{CI}}\,\mathbb{E}\big[(\omega p + (1-\omega)q)(\cdot)^\top\big]\,P_{\mathrm{CI}}
 \;\preceq\; P_{\mathrm{CI}}P_{\mathrm{CI}}^{-1}P_{\mathrm{CI}} = P_{\mathrm{CI}}. \qquad\square
$$

**증명 어디에도 $P_{ab}$ 가 나오지 않았다.** (10)이 $p$ 와 $q$ 의 결합분포와 무관한 항등식이기
때문이다. 이것이 CI 의 전부다.

**여유(보수성)의 정확한 크기.** (10)·(11)에서 버린 것을 모으면

$$
P_{\mathrm{CI}} - \tilde{P}_c = P_{\mathrm{CI}}\Big[\,\underbrace{\omega(1-\omega)\,\mathbb{E}[(p-q)(p-q)^\top]}_{\text{볼록성의 여유}}
 + \underbrace{\omega P_a^{-1}(P_a - \tilde{P}_a)P_a^{-1} + (1-\omega)P_b^{-1}(P_b-\tilde{P}_b)P_b^{-1}}_{\text{입력의 여유}}\Big]P_{\mathrm{CI}}. \tag{12}
$$

첫 항은 $p = q$ (거의 확실하게)일 때만 0 이다. 분산이 같은 스칼라($P_a = P_b = \sigma^2$,
상관계수 $\rho$, $\omega = \tfrac12$)에서는 $P_{\mathrm{CI}} = \sigma^2$,
$\tilde{P}_c = \sigma^2(1+\rho)/2$ 이므로

$$
\mathbb{E}[\mathrm{NEES}_{\mathrm{CI}}] = \frac{1+\rho}{2}, \qquad
\mathbb{E}[\mathrm{NEES}_{\text{독립 가정}}] = 1 + \rho. \tag{13}
$$

| $\rho$ | 독립 가정 융합 (실측 / 예측) | CI (실측 / 예측) |
|---|---|---|
| $0$ | $1.004$ / $1.0$ | $0.502$ / $0.50$ |
| $0.3$ | $1.299$ / $1.3$ | $0.649$ / $0.65$ |
| $0.6$ | $1.600$ / $1.6$ | $0.800$ / $0.80$ |
| $0.9$ | $1.908$ / $1.9$ | $0.954$ / $0.95$ |
| $1.0$ | $1.995$ / $2.0$ | $0.998$ / $1.00$ |

**두 융합이 반대쪽 끝에서 정확하다.** 독립 가정은 $\rho = 0$ 에서 딱 맞고 $\rho$ 가 커질수록
과확신한다. CI 는 $\rho = 1$ 에서 딱 맞고 $\rho$ 가 작아질수록 보수적이다 — 독립일 때는
$P_{\mathrm{CI}} = \sigma^2$ 로, **융합하지 않은 것과 같은 공분산**을 보고한다. CI 는 최악의
상관을 가정하는 융합이다.

**$\omega$ 의 선택.** (3)은 모든 $\omega$ 에서 일관적이므로 $\omega$ 는 성능 기준으로 고른다 —
보통 $\det P_{\mathrm{CI}}$ 나 $\operatorname{tr}P_{\mathrm{CI}}$ 를 최소화하는 1차원 탐색이다.
R1 의 수치 예에서 $\det$ 최소화는 $\omega = 0.837$ 을 주고 $\det P_{\mathrm{CI}} = 0.0360$ 으로
노드 $a$ 단독($0.0370$)보다 조금 작을 뿐이다. 그런데 **점 추정은 좋아진다** — 실제
$\operatorname{tr}\tilde{P}$ 가 $1.0294 \to 0.8987$ 이다. CI 는 "얻은 것을 다 보고하지 않는" 융합이다.

**가정이 깨지는 곳**: ⓐ 증명은 **입력이 일관적**($P_a \succeq \tilde{P}_a$)임을 썼다. 입력이
이미 과확신이면(R2 를 한 번이라도 거쳤다면) CI 의 출력도 과확신이다 — CI 는 과확신을 **만들지
않을** 뿐 **고치지** 않는다. ⓑ CI 는 평균과 공분산만으로 정의한 일관성을 보장한다. 분포가
다봉이거나 꼬리가 두꺼우면 $P \succeq \tilde{P}$ 이 "신뢰영역이 참값을 담는다"를 뜻하지 않는다.
ⓒ CI 를 **독립인** 정보(자기 센서의 새 측정)에 쓰면 정보를 버린다. 실무에서는 독립 부분과
상관을 모르는 부분을 나눠 앞은 칼만 갱신, 뒤만 CI 로 처리한다(split CI).

### R4 — 패킷 손실과 임계 도착 확률

**설정.** $x_{k+1} = ax_k + w_k$, $y_k = x_k + v_k$ ($w \sim \mathcal{N}(0,q)$,
$v\sim\mathcal{N}(0,r)$), 측정은 확률 $\gamma$ 로 도착한다(도착 여부 $\gamma_k \in \{0,1\}$ 는 서로
독립이고 **필터가 안다**). 예측 공분산 $P_k := P_{k\mid k-1}$ 의 재귀는

$$
P_{k+1} = a^2P_k + q - \gamma_k\,\frac{a^2P_k^2}{P_k + r}
 = \begin{cases} a^2P_k + q & \gamma_k = 0 \\[2pt] \dfrac{a^2rP_k}{P_k + r} + q & \gamma_k = 1 \end{cases} \tag{14}
$$

이다. **$P_k$ 가 확률변수가 된다** — 손실 패턴에 따라 달라지므로. 그래서 묻는 것은
$\mathbb{E}[P_k]$ 가 유계인가다.

**하한 (유계의 필요조건).** $\gamma_k = 1$ 인 가지에서 $a^2rP_k/(P_k+r) \ge 0$ 이므로 두 가지를
합쳐 $P_{k+1} \ge (1-\gamma_k)a^2P_k + q$. $\gamma_k$ 는 $P_k$ 와 독립이므로($P_k$ 는
$\gamma_0,\dots,\gamma_{k-1}$ 의 함수)

$$
\mathbb{E}[P_{k+1}] \;\ge\; (1-\gamma)a^2\,\mathbb{E}[P_k] + q. \tag{15}
$$

$(1-\gamma)a^2 \ge 1$ 이면 우변의 재귀가 발산하므로 $\mathbb{E}[P_k] \to \infty$.

**상한 (유계의 충분조건).** $\gamma_k = 1$ 인 가지에서 $a^2rP_k/(P_k + r) \le a^2r$ 이므로
$P_{k+1} \le (1-\gamma_k)a^2P_k + \gamma_ka^2r + q$ 이고

$$
\mathbb{E}[P_{k+1}] \;\le\; (1-\gamma)a^2\,\mathbb{E}[P_k] + \gamma a^2r + q. \tag{16}
$$

$(1-\gamma)a^2 < 1$ 이면 우변이 수렴하므로 $\mathbb{E}[P_k]$ 가 유계다. (15)(16)을 합치면
**유계 $\iff (1-\gamma)a^2 < 1 \iff \gamma > 1 - 1/a^2$**, 즉 (4)다.

**더 조인 상한.** (14)의 우변을 $g_{\gamma_k}(P_k)$ 라 쓰면, $P \mapsto P^2/(P+r)$ 이 볼록이므로
$g$ 는 $P$ 에 대해 오목이다. Jensen 으로
$\mathbb{E}[P_{k+1}] = \mathbb{E}[\bar{g}_\gamma(P_k)] \le \bar{g}_\gamma(\mathbb{E}[P_k])$
($\bar{g}_\gamma(P) = a^2P + q - \gamma a^2P^2/(P+r)$, **수정 Riccati**)이므로 그 고정점 $V$ 가
상한이고, (15)의 고정점 $S = q/(1-(1-\gamma)a^2)$ 가 하한이다:

$$
S \;\le\; \lim_k \mathbb{E}[P_k] \;\le\; V. \tag{17}
$$

**수치** ($a = 1.2$, $q = r = 1$, $\gamma_c = 0.3056$; 궤적 $4\times10^4$ 개, $k = 400$):

| $\gamma$ | $S$ | 실측 평균 | $V$ | 실측 중위수 |
|---|---|---|---|---|
| $1.0$ | $1.000$ | $1.952$ | $1.952$ | $1.952$ |
| $0.9$ | $1.168$ | $2.195$ | $2.211$ | $1.952$ |
| $0.75$ | $1.563$ | $2.752$ | $2.807$ | $1.982$ |
| $0.6$ | $2.358$ | $3.861$ | $3.988$ | $2.173$ |
| $0.2$ | $\infty$ | $6.7\times10^3$ – $4.5\times10^4$ (불안정) | $\infty$ | $10.5$ |

**마지막 줄이 요점이다.** $\gamma = 0.2 < \gamma_c$ 에서 **중위수는 $10.5$ 로 멀쩡**한데 평균은
수천에서 수만이고 표본을 뽑을 때마다 다르다($k = 200, 300, 400$ 에서 $6727$, $4058$, $45465$).
발산하는 것은 전형적 궤적이 아니라 **긴 연속 손실이라는 드문 사건**이 만드는 꼬리다. 따라서
"기댓값이 발산한다"는 정리를 "필터가 망가진다"로 읽으면 안 되고, "드문 긴 손실에서 오차가
임의로 커지며 그 빈도가 평균을 지배한다"로 읽어야 한다.

**분산의 임계.** 같은 논증을 $P_k^2$ 에 하면 $\gamma_k = 0$ 가지에서 $P_{k+1}^2 \ge a^4P_k^2$ 이므로
$\mathbb{E}[P_{k+1}^2] \ge (1-\gamma)a^4\,\mathbb{E}[P_k^2]$ 이고, 분산이 유한하려면
$\gamma > 1 - 1/a^4$ ($a = 1.2$ 에서 $0.5177$)이 필요하다. 그 사이($0.3056 < \gamma < 0.5177$)에서는
평균은 유한한데 **분산이 무한**이라 몬테카를로 평균이 수렴하지 않는 것처럼 보인다 — 위 표가
$\gamma \ge 0.6$ 만 평균을 비교하는 이유다(문제 P5).

**가정이 깨지는 곳**: ⓐ (4)의 **등호가 있는** 임계는 $C$ 가 가역(여기서는 스칼라)일 때다. 일반
계에서는 상·하한 $\underline{\gamma} \le \gamma_c \le \bar{\gamma}$ 만 알려져 있고
($\underline{\gamma} = 1 - 1/\max_i\lvert\lambda_i(A)\rvert^2$), 둘이 일치하지 않을 수 있다
(`sinopoli2004-intermittent-observations` §III). ⓑ 손실이 **독립**이라고 가정했다. 실제 무선
채널의 손실은 군집으로 온다(버스트). 마르코프 손실에서는 임계가 평균 손실률이 아니라 **손실
상태에 머무는 확률**로 정해진다. ⓒ 필터가 **손실을 안다**고 가정했다. 손실을 모르고 마지막
값을 새 측정처럼 다시 쓰면(zero-order hold) 일관성까지 깨진다 — 그것은 R5 와 같은 종류의
오류다.

### R5 — 지연된 측정

**설정.** 랜덤워크 $x_{k+1} = x_k + w_k$, $y_k = x_k + v_k$. 측정이 $d$ 스텝 늦게 도착하는데
필터가 그것을 **현재** 측정처럼 쓴다: 시각 $k$ 에 $y_{k-d}$ 를 $x_k$ 의 측정으로 갱신한다.

**핵심 관찰.** 이 필터의 재귀(예측 $P \leftarrow P + q$, 갱신 $K = P/(P+r)$)는 측정열
$y_1, y_2, \dots$ 를 한 번씩 순서대로 쓰는 **표준 칼만 필터와 글자 그대로 같다**. 다른 것은
시계뿐이다. 따라서 시각 $k$ 의 추정 $\hat{x}_k$ 는 사실

$$
\hat{x}_k = \mathbb{E}\big[x_{k-d} \mid y_{1:k-d}\big]
$$

이고 그 오차 분산은 정상상태 사후 분산 $P_\infty$ 다. $P_\infty$ 는
$P = (P+q)r/(P+q+r)$ 의 양의 해, 즉 $P^2 + qP - qr = 0$ 에서 (5)의 식이다.

**실제 오차.** 필터가 추정한다고 **주장하는** 것은 $x_k$ 다. $x_k = x_{k-d} + \sum_{i=k-d}^{k-1}w_i$ 이므로

$$
\hat{x}_k - x_k = \underbrace{(\hat{x}_k - x_{k-d})}_{\text{분산 } P_\infty}
 - \underbrace{\textstyle\sum_{i=k-d}^{k-1}w_i}_{\text{분산 } dq},
$$

두 항은 독립이다($\hat{x}_k$ 는 $y_{1:k-d}$ 의 함수이고 미래의 과정 잡음과 무관). 따라서 실제
분산은 $P_\infty + dq$ 인데 보고는 $P_\infty$ 이므로 (5)가 나온다.

| 지연 $d$ | 0 | 1 | 2 | 4 | 8 |
|---|---|---|---|---|---|
| 예측 $1 + dq/P_\infty$ | $1.000$ | $1.863$ | $2.727$ | $4.453$ | $7.907$ |
| 실측 NEES | $0.998$ | $1.857$ | $2.718$ | $4.434$ | $7.866$ |

($q = 0.2$, $r = 0.5$, $P_\infty = 0.2317$, 궤적 $2\times10^4$ 개의 마지막 50스텝 평균.)

**고치는 법.** 지연 $d$ 를 **알면** 해법은 한 줄이다: 추정은 $x_{k-d}$ 의 것이므로 $d$ 스텝
**예측**해 보고한다. 랜덤워크에서는 추정값이 그대로이고 공분산이 $P_\infty + dq$ 가 되어 NEES 가
1 로 돌아온다. 일반 계에서는 $\hat{x}_k = A^d\hat{x}_{k-d}$,
$P = A^dP_\infty(A^d)^\top + \sum_{i=0}^{d-1}A^iQ(A^i)^\top$ 다. 지연이 측정마다 달라 **순서가
뒤바뀌어** 도착하면(out-of-sequence) 이미 갱신한 상태를 과거로 되돌려 갱신해야 하고, 그 정확한
한 스텝 해가 `bar-shalom2002-oosm` 이다.

**가정이 깨지는 곳**: ⓐ "한 줄 해법"은 지연을 **아는** 경우다. 타임스탬프가 없거나 시계가
동기화되지 않으면 $d$ 자체가 추정 대상이 된다. ⓑ (5)는 랜덤워크($a = 1$)의 식이다. 안정한
계($\lvert a\rvert < 1$)에서는 과거 상태가 현재에 덜 남으므로 지연의 비용이 포화하고, 불안정한
계에서는 $a^{2d}$ 로 폭발한다(문제 P4). ⓒ 지연을 보정해도 **정보는 돌아오지 않는다** — 보고
공분산이 $P_\infty + dq$ 로 커진 것은 정직해진 것이지 좋아진 것이 아니다. 지연은 일관성 문제이기
전에 성능 문제다.

## 증명 스케치

### R1' — 공통 사전정보를 무시한 융합은 엄격히 과확신이다 [D3]

**가설**
H1: 두 노드가 같은 사전정보 $(x_0, P_0)$, $P_0 \succ 0$ 를 갖는다.
H2: 각 노드의 측정이 선형이고 잡음이 가우시안이며, $n_a$, $n_b$, $e_0$ 가 서로 독립이다.
H3: 각 노드가 자기 측정으로 **정확한** 갱신 (6)을 했다(각 입력은 일관적이고 딱 맞다).

**결론** C: 독립 가정 융합의 실제 공분산이 $\tilde{P}_n = P_n + 2P_n\Lambda_0P_n$ 이고
$\tilde{P}_n - P_n \succ 0$ 이다. 즉 모든 방향에서 과확신이다.

**전략**: 두 오차를 독립 원천 $(e_0, n_a, n_b)$ 의 선형결합으로 쓰고 공유되는 원천을 찾는다.

1. **오차의 분해.** H2·H3 로 (7): $e_a = P_a\Lambda_0e_0 + P_aH_a^\top R_a^{-1}n_a$.
2. **교차공분산.** H2 의 독립성으로 교차항에는 $e_0$ 만 남는다:
   $P_{ab} = P_a\Lambda_0P_0\Lambda_0P_b = P_a\Lambda_0P_b$.
3. **융합 오차의 공분산.** $e_c = P_n(P_a^{-1}e_a + P_b^{-1}e_b)$ 를 전개하고 H3 로
   $\mathbb{E}[e_ae_a^\top] = P_a$ 를 쓰면 대괄호가 $P_a^{-1} + P_b^{-1} + 2\Lambda_0$.
4. **엄격성.** H1 의 $P_0 \succ 0$ 에서 $\Lambda_0 \succ 0$, $P_n \succ 0$ 이므로
   $P_n\Lambda_0P_n \succ 0$ (합동변환은 양정부호를 보존). **C**.

**가설을 지우면 어디서 무너지는가**

- **H1 을 약화하면**(사전정보가 한 방향에서 무한히 약함, $\Lambda_0$ 가 특이): 4단계의 엄격
  부등식이 $\succeq$ 로 약해진다. 사전정보가 없는 방향에서는 이중 계산할 것이 없으므로 그
  방향의 융합은 정확하다. 과확신은 **공유한 정보가 있는 방향에서만** 생긴다.
- **H2 의 독립성을 지우면**(두 노드의 측정 잡음이 상관): 2단계에 $n_a$, $n_b$ 의 교차항이
  더해진다. 그 부호는 정해져 있지 않으므로 과확신이 더 커질 수도, **음의 상관이면 줄어들
  수도** 있다. "상관을 무시하면 항상 과확신"은 거짓이고, 정확한 진술은 "교차항의 대칭 부분이
  PSD 이면 과확신"이다(문제 P7).
- **H3 를 지우면**(입력이 이미 과확신): 3단계의 $\mathbb{E}[e_ae_a^\top] = P_a$ 가 $\succ P_a$ 로
  바뀌어 과확신이 더해진다. R2 가 그 경우다.

## 문제 세트

해답 방침은 문제마다 적어 두었다. 난이도: ★ 15분 / ★★ 1시간 / ★★★ 하루 이상.

**P1 (유도, ★★, R1)** (8)의 $c^\star$ 가 두 측정 $y_a$, $y_b$ 를 한 노드에 모아 한 번에 갱신한
중앙집중 해와 같음을 보여라. 그 다음 로봇이 3대이고 통신 그래프가 **삼각형**일 때, 링크별
뺄셈만으로는 공통 정보를 올바르게 뺄 수 없는 구체적 메시지 순서를 하나 만들어라.
*해답 스케치*: 중앙집중 해의 정보는 $\Lambda_0 + H_a^\top R_a^{-1}H_a + H_b^\top R_b^{-1}H_b$ 이고
(6) 두 개를 더하면 $\Lambda_0$ 가 한 번 더 들어 있다. 정보 벡터도 같은 방식으로 맞춘다. 삼각형
에서는 $a \to b$, $b \to c$, $c \to a$ 순으로 보내면 $a$ 가 $c$ 에게서 받은 정보 안에 자기 정보가
들어 있는데 링크 $c$–$a$ 의 기록에는 그것이 없다.

**P2 (증명, ★, R3)** 항등식 (10)을 전개로 증명하고, 그것이 $p$, $q$ 의 결합분포에 대한 어떤
가정도 쓰지 않음을 확인하라. 그 다음 세 개 이상의 추정에 대한 CI
($P^{-1} = \sum_i\omega_iP_i^{-1}$, $\sum_i\omega_i = 1$)의 일관성을 같은 방식으로 증명하라.
*전략 + 핵심 부등식*: 좌변을 $\omega(1-\omega)$ 로 묶는다. 여러 개일 때는
$\sum_i\omega_ip_ip_i^\top - (\sum_i\omega_ip_i)(\cdot)^\top = \sum_{i<j}\omega_i\omega_j(p_i-p_j)(p_i-p_j)^\top$
를 보이면 된다(분산의 쌍별 표현). 전개는 숨긴다.

**P3 (증명, ★★★, R4)** (15)–(17)을 빠진 줄 없이 쓰고, ⓐ $\bar{g}_\gamma$ 의 오목성을 2계
도함수로 확인하고 ⓑ $\gamma > \gamma_c$ 에서 수정 Riccati 의 고정점 $V$ 가 존재하고 유일함을
보이고 ⓒ $\gamma \to 1$ 에서 $V$ 가 표준 Riccati 해로 가고 $S$ 는 가지 **않음**을 보여 하한이
느슨한 이유를 설명하라.
*전략 + 핵심 부등식*: ⓐ $d^2/dP^2\,[P^2/(P+r)] = 2r^2/(P+r)^3 > 0$. ⓑ $\bar{g}_\gamma$ 가 오목·
증가이고 $\bar{g}_\gamma(0) = q > 0$, 큰 $P$ 에서 기울기가 $(1-\gamma)a^2 < 1$ 임을 쓴다.
ⓒ $S \to q$ 인데 표준 해는 $q$ 보다 크다 — (15)가 도착한 가지의 $a^2rP/(P+r)$ 를 통째로
버렸기 때문이다.

**P4 (유도, ★★, R5)** (5)를 일반 스칼라 계 $x_{k+1} = ax_k + w_k$ 로 확장하라. 지연된 측정을
최신으로 쓴 필터의 실제 분산과 NEES 를 $a$, $d$, $q$, $P_\infty$ 로 쓰고, $\lvert a\rvert < 1$ 과
$\lvert a\rvert > 1$ 에서 $d \to \infty$ 의 거동을 비교하라.
*해답 스케치*: 필터는 여전히 $x_{k-d}$ 의 올바른 추정기다(재귀가 같다). $x_k = a^dx_{k-d} + \sum_ia^iw$
이므로 오차는 $(\hat{x} - x_{k-d}) + (1 - a^d)x_{k-d} - \sum_i a^iw$ 인데, 가운데 항 때문에 오차가
**상태 자체의 크기**에 의존한다 — 랜덤워크에서는 없던 항이다. $\lvert a\rvert < 1$ 이면 정상
분산으로 포화하고 $\lvert a\rvert > 1$ 이면 $a^{2d}$ 로 커진다.

**P5 (계산, ★, R4)** $a = 1.2$, $q = r = 1$ 에서 ⓐ $\gamma_c$ 와 분산의 임계 $1 - 1/a^4$ 를
구하고 ⓑ $\gamma = 0.6, 0.75, 0.9, 1.0$ 에서 $S$ 와 $V$ 를 소수 셋째 자리까지 구하라.
*정답*: ⓐ $\gamma_c = 1 - 1/1.44 = 0.3056$, 분산 임계 $1 - 1/2.0736 = 0.5177$.
ⓑ $S = 2.358, 1.563, 1.168, 1.000$; $V = 3.988, 2.807, 2.211, 1.952$ (허용오차 $\pm0.002$).
*검산*: $V$ 를 $\bar{g}_\gamma$ 에 넣어 잔차 $< 10^{-9}$ 인지, $\gamma = 1$ 의 $V$ 가
$P = a^2rP/(P+r) + q$ 의 양의 해 $1.9522$ 인지 확인한다.

**P6 (구현, ★★★, R1·R2)** 두 노드가 같은 랜덤워크 표적을 각자 추적하면서 $m$ 스텝마다 추정을
교환해 독립으로 융합하는 시뮬레이션을 만들고, 교환 주기 $m \in \{1, 5, 20\}$ 에 대해 NEES 와
**실제** 평균제곱오차를 중앙집중 필터와 비교하라. 같은 설정에서 CI 융합도 구현하라.
*루브릭*: ⓐ 독립 가정 융합의 NEES 가 $m$ 이 작을수록(자주 교환할수록) 큰 것을 보인다
ⓑ 독립 가정 융합의 **실제 오차**도 중앙집중보다 나쁜 것을 보인다(과확신한 필터가 새 측정을
덜 믿는다) ⓒ CI 의 NEES 가 모든 $m$ 에서 1 이하임을 보인다 ⓓ 공통 난수를 써서 세 방식을 같은
궤적에서 비교한다.

**P7 (반례, ★★, R1·R3)** ⓐ "상관을 무시한 융합은 항상 과확신이다"의 반례를 만들라 — 교차공분산이
**음**인 두 추정을 독립으로 융합하면 보수적임을 스칼라로 보이면 된다. ⓑ "CI 는 항상 독립 가정
융합보다 나쁜 점 추정을 낸다"의 반례를 찾거나, 못 찾으면 어디까지 탐색했는지 적으라.
*성질 체크리스트*: ⓐ 는 (13)의 $1 + \rho$ 가 $\rho < 0$ 에서 1 아래임을 쓰고 음의 상관이 실제로
생기는 물리적 상황 하나(예: 두 추정이 **합이 일정한** 제약을 나눠 가진 경우)를 든다. ⓑ 는
$\rho \to 1$ 이고 분산이 **다른** 경우를 조사해야 한다 — 그때 독립 가정 융합의 가중치가 최적이
아니다. 한 축만 바꾸면 미달.

**P8 (논문, ★★, R3·R4)** `julier1997-covariance-intersection` 2-3절과
`sinopoli2004-intermittent-observations` II-III 절을 읽고 ⓐ Julier-Uhlmann 의 일관성 정의가 본문
표의 정의와 같은지 ⓑ 저자들이 $\omega$ 를 어떤 기준으로 고르는지 ⓒ Sinopoli 등의 상·하한이
본문 (15)–(17)과 어떻게 대응하는지 ⓓ 일반 계에서 임계 확률의 상·하한이 일치하는 조건이
무엇인지 각각 3문장 이내로 쓰라.
*루브릭*: ⓐⓑ 는 식을 인용하면 통과. ⓒ 는 수정 대수 Riccati 방정식(MARE)과 선형 하한을 각각
짚어야 한다. ⓓ 가 핵심 — "$C$ 가 가역일 때"를 짚으면 통과, 일반적으로는 열린 문제였다는 것까지
쓰면 우수.

# Part A/B/C: 공통 사전정보를 공유하는 두 노드 (d = 3)

def mean_nees(est, truth, cov):
    """평균 NEES. est, truth 는 (N, d), cov 는 (d, d) 보고 공분산."""
    err = est - truth
    return float(np.mean(np.einsum("ni,ij,nj->n", err, np.linalg.inv(cov), err)))

   평균은 $10^3$ 을 넘는다. 평균의 값 자체는 수용 기준이 아니다(수렴하지 않는다) — **중위수와
   평균의 괴리를 명시적으로 출력**하는 것이 기준이다.
5. **Part E** — ⓐ $d = 0, 1, 2, 4, 8$ 의 NEES 가 $1.000, 1.863, 2.727, 4.453, 7.907$ 과
   상대오차 2% 이내다. ⓑ 보정 필터의 NEES 가 모든 $d$ 에서 $1.00 \pm 0.03$ 이다.
   ⓒ 보고 공분산이 지연과 무관하게 $P_\infty = 0.2317$ 임을(상대오차 $10^{-4}$) 확인한다 —
   **필터는 자기가 늦었다는 것을 모른다.**

**비교 대상**: ⓐ Part A·B·C 의 베이스라인은 채널 필터(= 중앙집중 최적)다. ⓑ Part C 의 스칼라

표준 칼만 필터다. ⓓ Part E 는 $d = 0$ 과 보정 필터가 베이스라인이다.

## 열린 문제

- **(열린 문제) 사이클이 있는 통신 그래프에서의 정확한 공통 정보 제거** — R1 의 뺄셈은 트리에서만
  정확하고, 사이클이 있으면 CI 로 물러나 정보의 큰 부분을 버린다(독립일 때 절반 — (13)).
  현재 접근: 정보의 출처를 꼬리표로 달아 전달하는 방법(메시지가 로봇 수에 비례해 커진다)과
  분산 포즈 그래프처럼 **원 인자**를 교환하는 방법(`s5-distributed-optimization`). 비어 있는
  자리: 메시지 크기를 상수로 유지하면서 CI 보다 엄격히 덜 보수적이고 일관성이 증명되는 융합.
- **(열린 문제) 일관성과 보수성 사이의 교환을 재는 척도** — CI 는 최악의 상관을 가정해
  $\mathbb{E}[\mathrm{NEES}]$ 를 $d$ 아래로 누른다. 상관의 **범위**를 알면(예: $\lvert\rho\rvert\le\bar\rho$)
  덜 보수적인 융합이 가능하지만(bounded-correlation CI 류), 그 범위를 실제 시스템에서
  **데이터로 추정하고 검증하는** 절차가 확립되지 않았다. 현재 접근: 타원 교집합 기반 융합과
  역공분산 교차. 비어 있는 자리: 상관 범위의 온라인 추정과 그 추정 오차가 일관성 보장에
  전파되는 방식.
- **(열린 문제) 버스트 손실과 비선형 추정기** — R4 의 임계는 독립 손실·선형 계·알려진 손실의
  결과다. 시각-관성 SLAM 처럼 비선형이고 선형화점이 추정에 의존하는 추정기에서, 통신·지각
  단절이 길어질 때 **발산이 시작되는 단절 길이**를 사전에 한계짓는 이론이 없다. 현재 접근:
  마르코프 손실 모형에서의 임계 조건과 경험적 단절 내성 시험. 비어 있는 자리: 비선형 추정기의
  단절 내성을 관측가능성 구조(`c5-observability-consistency`)에서 예측하는 방법.
