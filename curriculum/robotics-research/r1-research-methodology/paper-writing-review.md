# 논문 작성과 리뷰

## 도달 목표

논문은 연구의 **보고서가 아니라 주장의 구조물**이다. 좋은 결과를 나쁘게 쓰면 거절되고, 나쁜 결과를
정직하게 잘 쓰면 받아들여지기도 한다. 이 레슨은 쓰기와 읽기를 **같은 기술**로 훈련한다:
리뷰어의 눈을 가지면 자기 논문의 약점이 보인다.

**이 레슨의 핵심 주장**: 논문의 설계는 글쓰기 전에 끝나야 한다. 기여 문장 하나를 정하고,
각 절이 그 문장을 어떻게 지지하는지 배치한 뒤에 문장을 쓴다. 역순으로 하면 "한 일을 나열한 글"이
되고, 리뷰어는 기여를 찾지 못한다.

산출물: **8페이지 초안 + 타인 논문 리뷰 1편 + 반론 초안**.

## 시작 전 자가 진단

| 질문 | 할 수 있으면 | 못 하면 |
|---|---|---|
| 자기 연구의 기여를 한 문장으로 말할 수 있는가? | 절차 2단계부터 | `r1-research-questions` 의 제안서로 돌아간다 |
| 실험 결과와 신뢰구간이 준비됐는가? | 절차를 순서대로 | 앞 두 레슨(평가·재현성)을 먼저 끝낸다 |
| 남의 논문을 읽고 **반증 가능한 약점**을 지적해 본 적이 있는가? | 4단계를 빠르게 | 4단계 정독 — 리뷰 훈련이 이 레슨의 절반이다 |

## 절차

**1단계 — 기여 문장을 고정한다 (1시간).** 한 문장, 능동태, 검증 가능하게:
"우리는 X 조건에서 Y 를 Z 만큼 개선한다" 또는 "우리는 X 가 Y 때문에 실패함을 보인다".
형용사("새로운", "효율적인")로는 기여를 쓸 수 없다. 기여가 **두 개 이상**이면 하나를 주로
정하고 나머지를 부수적으로 내린다 — 균등한 기여 세 개는 기여 영 개로 읽힌다.

**2단계 — 절 구조를 기여에서 역설계한다 (2시간).** 각 절의 **존재 이유**를 한 줄로 적는다:
- **도입**: 문제의 중요성 → 기존 접근의 **구체적** 한계 → 우리 기여 문장 → 증거 요약.
  마지막 단락이 "기여 목록"이다.
- **관련 연구**: 나열이 아니라 **우리 기여와의 경계선 그리기**. 각 묶음에 "그래서 그들은 X 를
  못 한다"가 있어야 한다.
- **방법**: 재구현 가능한 최소 정보. 왜 이 선택인지(설계 근거)를 쓰고, 안 되는 것도 쓴다.
- **실험**: 각 소절이 **하나의 질문에 답한다**. "질문 → 설정 → 결과 → 해석" 순서를 지킨다.
- **한계**: 숨기면 리뷰어가 찾아낸다. 먼저 쓰면 신뢰가 올라간다.
구조가 끝나면 **각 절에 해당 그림·표를 배치**한다. 글은 그다음이다.

**3단계 — 그림을 먼저 설계한다 (3시간).** 리뷰어는 그림부터 본다.
- 그림 1개 = 주장 1개. 그림에서 전달할 문장을 먼저 쓰고 그림을 만든다.
- **캡션은 자립적으로**: 본문을 안 읽어도 무엇을 보는지, 무엇이 결론인지 알 수 있게.
- 축·단위·오차막대(신뢰구간)·시행 수를 반드시 표시한다. 오차막대 없는 비교 그림은 근거가 아니다.
- 지각적으로 균일한 색을 쓰고 흑백 인쇄와 색각 이상에서 읽히는지 확인한다.
- 시스템 그림(파이프라인)은 **데이터 흐름**을 보여 주고, 각 블록이 본문의 어느 절에 대응하는지 맞춘다.

**4단계 — 리뷰어가 되어 공격한다 (3시간).** 자기 논문을 **다른 사람의 논문처럼** 읽고 §리뷰 양식
으로 리뷰를 쓴다. 공격 지점 목록:
ⓐ 기여 문장이 실험으로 지지되는가(주장 > 증거면 거절 사유다)
ⓑ 베이스라인 튜닝 예산이 동등한가 ⓒ 시행 수와 구간이 있는가 ⓓ ablation 이 기여를 분해하는가
ⓔ 수식과 구현이 일치하는가 ⓕ 한계가 진짜 한계인가(형식적 문장이 아닌가)
**각 공격에 대해 ① 본문을 고치거나 ② 한계로 인정하거나 ③ 추가 실험을 돌린다.** 세 가지 중 하나다.

**5단계 — 타인 논문 리뷰 1편을 쓴다 (3시간).** 실제 리뷰 양식(요약 / 강점 / 약점 / 질문 / 한계 /
점수 / 확신도)으로 쓴다. 규칙:
- **요약을 먼저**: 저자가 "내 논문을 이해했다"고 느낄 수 있어야 한다.
- 약점은 **구체적이고 조치 가능하게**: "실험이 약하다"(X) → "표 2 는 시드 3개이고 구간이 없어
  3.1절의 주장을 지지하지 못한다. 10시드와 95% 구간이 필요하다"(O).
- 저자가 아니라 **논문**을 평가한다. 추측(저자가 모를 것이다)과 요구(내 논문을 인용하라)는 금지.
- 기밀 유지: 심사 중 원고를 외부에 공유하거나 **생성 모델에 입력하지 않는다**(학회 규정).

**6단계 — 반론(rebuttal)을 쓴다 (2시간).** 형식: ⓐ 감사와 쟁점 분류 ⓑ **가장 치명적인 지적을
먼저** ⓒ 각 지적에 근거(새 실험 수치, 본문 위치)로 답하고 ⓓ 맞는 지적은 즉시 인정하고 수정안을 제시.
**논쟁하지 않고 증거를 댄다.** 지면이 부족하면 쟁점의 우선순위로 자른다.

**연구 윤리 (항상)**: 중복 투고 금지, 저자권(실제 기여자만, 순서는 합의), 데이터·그림 조작 금지
(이상치 제거는 사전 기준으로만), 이해 상충 공개, 생성 모델 사용 시 학회 규정 확인, 인용 누락 방지.
**결과를 좋게 보이려고 실패 설정을 보고하지 않는 것은 선택적 보고(selective reporting)이며 부정에 가깝다.**

## 판정 기준

| 항목 | 통과 | 우수 |
|---|---|---|
| 기여 문장 | 한 문장으로 명시된다 | 검증 가능하고, 각 절이 그 문장을 지지하도록 배치됨 |
| 구조 | 표준 절 구성을 따른다 | 각 절에 존재 이유가 있고 실험 소절이 질문 1개씩에 답함 |
| 그림 | 축·단위가 있다 | 그림 1개 = 주장 1개, 자립 캡션, 오차막대와 시행 수 표시, 흑백·색각 확인 |
| 한계 | 한계 절이 있다 | 실제 약점(검정력 부족, 미검증 가정)을 구체적으로 적음 |
| 리뷰 | 양식을 채웠다 | 약점이 조치 가능하고 근거(절·표 번호)를 가지며 어조가 전문적 |
| 반론 | 모든 지적에 답했다 | 치명적 순서로 배치하고 새 증거를 제시하며 맞는 지적을 인정 |

## 실패 사례

- **기여를 형용사로 쓴다.** "새롭고 효율적인 프레임워크"는 기여가 아니다.
- **기여가 세 개다.** 균등한 셋은 리뷰어에게 영으로 읽힌다.
- **관련 연구가 목록이다.** 경계선을 긋지 않으면 "차이가 뭔가"가 첫 질문이 된다.
- **그림에 오차막대가 없다.** 비교 주장의 근거가 사라진다.
- **캡션이 "결과"뿐이다.** 리뷰어는 그림만 보고 판단하는 경우가 많다.
- **한계 절이 형식적이다.** "향후 더 많은 실험이 필요하다"는 한계가 아니다.
- **실패 설정을 보고하지 않는다.** 선택적 보고이며 윤리 문제다.
- **반론에서 논쟁한다.** 감정적 반박은 점수를 낮춘다. 증거만 댄다.
- **리뷰에서 저자를 추측한다.** 이중 블라인드 위반이고 리뷰 품질을 떨어뜨린다.

## 사례 연구

**필독 1편 + 도입부 해부 2편.**

**Lipton & Steinhardt, "Troubling trends in machine learning scholarship" (2018)** — `반론`.
질문: ⓐ 저자들이 지적한 네 가지 경향은 무엇이고 각각이 독자를 어떻게 오도하는가?
ⓑ "설명(explanation)과 추측(speculation)의 혼동"의 예를 자기 분야 논문에서 찾아라.
ⓒ 수학적 외양(mathiness)이 왜 문제인가 — 수식이 많은 것과 무엇이 다른가?
ⓓ 자기 초안에서 네 경향 각각에 해당하는 문장을 찾아 고쳐라.

**도입부 해부**: 자기 분야 상위 학회 논문 2편의 도입부를 문장 단위로 쪼개 각 문장의 **기능**을
표로 적는다(중요성 / 기존 한계 / 기여 / 증거 요약 / 구성). 그리고 자기 초안의 도입부를 같은 표로
만들어 빠진 기능을 찾는다. **보조 자료**로 Agarwal et al. (2021) 의 보고 방식 권고를 함께 보고,
자기 실험 절의 보고 형식을 점검한다.

## 산출물 과제

**산출물 1 — 8페이지 초안** (학회 양식)
- 구성: 도입, 관련 연구, 방법, 실험, 한계, 결론 + 참고문헌(분량 제한 외) + 부록(선택).
- 기여 문장 1개, 그림 3개 이상(각각 주장 1개, 자립 캡션, 오차막대), 주 결과 표 1개(구간 포함).
- **수용 기준**: ⓐ 기여 문장이 실험 절의 특정 표·그림으로 추적 가능 ⓑ 모든 비교에 시행 수와
  구간 ⓒ 한계 절이 구체적 ⓓ 재현 저장소 링크(앞 레슨의 산출물).

**산출물 2 — 타인 논문 리뷰 1편** (1–1.5페이지)
- 대상: 최근 1년 내 공개된 자기 분야 논문(arXiv 가능).
- 양식: 요약 / 강점 / 약점 / 질문 / 한계 평가 / 점수와 확신도.
- **수용 기준**: 약점 3개 이상이 각각 **절·표 번호를 지목**하고 **조치 가능한 요구**를 포함.

**산출물 3 — 자기 논문 반론 초안** (1페이지)
- 4단계에서 자기 논문에 쓴 리뷰의 지적 5개에 답하는 반론.
- **수용 기준**: 치명적 순서로 배치, 각 답변이 수치나 본문 위치를 인용, 최소 1개는 **인정과
  수정안**(반박이 아니라).

**수용 기준**: 세 산출물이 §판정 기준에서 모두 통과 이상, 그리고 동료 1명의 리뷰를 받아
지적 중 **최소 3개를 초안에 반영**했다.

## 열린 문제

- **(열린 문제) 심사의 신뢰도** — 같은 논문에 대한 리뷰어 간 일치도가 낮다는 보고가 반복된다.
  대규모 학회에서 심사 품질을 유지하는 방법(심사 보상, 리뷰어 교육, 메타리뷰 설계)이 미해결이다.
- **(열린 문제) 부정 결과의 출판 경로** — 재현 실패와 음성 결과는 가치가 있지만 발표 지면이 적다.
  이 편향(publication bias)이 분야의 지식을 왜곡하는 크기를 측정하기 어렵다.
- **(열린 문제) 생성 모델과 저술·심사** — 초안 작성과 리뷰 작성에 대형 모델을 쓰는 범위에 대한
  규범이 학회마다 다르고 변하고 있다. 기밀 유지와 저자권의 경계가 정립되지 않았다.

## 이 단계 공부법

1. **기여 문장을 10번 고쳐 쓴다 (1시간)** — 동료에게 문장만 보여 주고 "무엇을 했는지" 되물어
   본다. 설명이 필요하면 아직 안 된 것이다.
2. **그림을 글보다 먼저 만든다 (3시간)** — 그림 3개와 캡션이 완성되면 논문의 골격이 선다.
   오차막대와 시행 수를 처음부터 넣는다.
3. **도입부를 문장 기능 표로 해부한다 (2시간)** — 남의 논문 2편과 자기 초안. 빠진 기능이 곧
   리뷰어의 첫 질문이다.
4. **자기 논문에 리뷰를 쓴다 (3시간)** — 실제 양식으로, 점수까지. 가장 효율적인 품질 개선
   수단이고, 4단계의 공격 목록 여섯 항목을 그대로 쓴다.
5. **실제로 리뷰 1편을 쓴다 (3시간)** — 쓰는 눈과 읽는 눈은 같은 근육이다. 기밀 유지 규정을
   지키고(원고를 외부 서비스에 넣지 않는다) 어조를 전문적으로 유지한다.
6. **반론 초안으로 마감한다 (2시간)** — 자기 리뷰의 지적 5개에 답한다. 답할 수 없는 지적이
   남으면 그것이 **한계 절에 들어갈 문장**이다.
