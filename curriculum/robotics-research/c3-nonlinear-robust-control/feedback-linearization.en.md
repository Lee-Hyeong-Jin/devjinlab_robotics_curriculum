# Feedback linearisation and controllability

## Setup and notation

`c3-lyapunov-stability` built the tools for **deciding** stability. This lesson is an attempt to
**change coordinates** so the problem becomes a linear one, and it is about where that attempt
fails. Where it fails is what governs control and planning for nonholonomic robots
(differential-drive robots, cars, satellites).

Assumed: vector fields and flows, Jacobians, the implicit function theorem. Lie brackets and
distributions are defined and used here — no differential geometry course is needed.

| Symbol | Meaning |
|---|---|
| $\dot{x} = f(x) + \sum_{i=1}^m g_i(x)u_i$ | a system affine in the input; $f$ the drift, $g_i$ the input vector fields |
| $L_f h$ | Lie derivative $\nabla h(x)^\top f(x)$; $L_f^k h$ iterates it $k$ times |
| $[f, g]$ | Lie bracket $\dfrac{\partial g}{\partial x}f - \dfrac{\partial f}{\partial x}g$ |
| $\operatorname{ad}_f^k g$ | $\operatorname{ad}_f^0 g = g$, $\operatorname{ad}_f^{k}g = [f, \operatorname{ad}_f^{k-1}g]$ |
| $\Delta = \operatorname{span}\{g_1,\dots,g_m\}$ | a distribution: a subspace of the tangent space at each point |
| the distribution is **involutive** | $[X,Y] \in \Delta$ for all $X, Y \in \Delta$ |
| $\rho$ | relative degree: $L_{g}L_f^{k}h = 0$ for $k<\rho-1$ and $L_gL_f^{\rho-1}h \ne 0$ |
| $q = (x, y, \theta)$ | pose of a planar differential-drive robot; $u_1$ forward speed, $u_2$ angular rate |
| $z = (z_1,z_2,z_3)$ | chained-form coordinates, with inputs $v = (v_1,v_2)$ |
| $\Phi^X_t(x)$ | the flow of the vector field $X$: $\frac{d}{dt}\Phi^X_t = X(\Phi^X_t)$, $\Phi^X_0 = \operatorname{id}$ |

The running example of this lesson is the differential-drive robot:

$$
\dot{q} = \underbrace{\begin{bmatrix}\cos\theta\\ \sin\theta\\ 0\end{bmatrix}}_{g_1(q)}u_1
  + \underbrace{\begin{bmatrix}0\\ 0\\ 1\end{bmatrix}}_{g_2(q)}u_2, \qquad f \equiv 0. \tag{1}
$$

There is no drift ($f=0$) and there are fewer inputs than states ($m=2 < n=3$) — those two facts
explain the whole second half of this lesson.

## Key results

The bracket is the derivation depth (`research_notes/연구 트랙 설계/lesson-standard.md` §2).

- **R1 (condition for full feedback linearisation) [D3]** — a single-input system
  $\dot x = f(x) + g(x)u$ is turned, near $x_0$, into a controllable linear system
  $\dot\xi = A\xi + Bv$ by a change of coordinates $\xi = \Phi(x)$ and of input
  $u = \alpha(x) + \beta(x)v$ **if and only if**
  (i) $\operatorname{rank}\{g, \operatorname{ad}_fg, \dots, \operatorname{ad}_f^{n-1}g\} = n$ and
  (ii) $\Delta_{n-1} = \operatorname{span}\{g, \dots, \operatorname{ad}_f^{n-2}g\}$ is involutive.
  Without (ii) a linearising output $h$ **does not exist** — that is what the Frobenius theorem
  tells us.
- **R2 (input-output linearisation and zero dynamics) [D2]** — if the output $y=h(x)$ has
  relative degree $\rho$, then
  $$
  u = \frac{1}{L_gL_f^{\rho-1}h(x)}\big(v - L_f^{\rho}h(x)\big) \tag{2}
  $$
  makes the input-output map $y^{(\rho)} = v$. The remaining $n-\rho$ dimensions of internal
  dynamics become the **zero dynamics** $\dot\eta = q(0,\eta)$ under the input that holds
  $y\equiv0$, and if those are unstable, exact tracking makes the internal state diverge.
- **R3 (Lie bracket motion and Chow-Rashevskii) [D2]** — composing four flows alternately gives
  $$
  \Phi^{g_2}_{-\varepsilon}\circ\Phi^{g_1}_{-\varepsilon}\circ\Phi^{g_2}_{\varepsilon}\circ
    \Phi^{g_1}_{\varepsilon}(x) = x + \varepsilon^2 [g_1,g_2](x) + O(\varepsilon^3). \tag{3}
  $$
  Hence if the Lie algebra generated by the brackets spans $\mathbb{R}^n$ at every point (LARC,
  bracket-generating), a driftless system is **locally reachable** (Chow-Rashevskii). For (1),
  $[g_1,g_2] = (\sin\theta, -\cos\theta, 0)^\top$ and
  $\det[g_1\ g_2\ [g_1,g_2]] = 1$, so it is controllable.
- **R4 (chained form and steering with sinusoids) [D2]** — the transformation
  $$
  z_1 = \theta,\quad z_2 = x\cos\theta + y\sin\theta,\quad z_3 = x\sin\theta - y\cos\theta,
    \qquad v_1 = u_2,\quad v_2 = u_1 - u_2 z_3 \tag{4}
  $$
  turns (1) into the chained form $\dot z_1 = v_1$, $\dot z_2 = v_2$, $\dot z_3 = z_2v_1$. Over one
  period $T = 2\pi/\omega$ of $v_1 = a\sin\omega t$, $v_2 = b\cos\omega t$, the coordinates
  $z_1,z_2$ return to where they started and
  $$
  \Delta z_3 = \frac{\pi a b}{\omega^2}. \tag{5}
  $$
- **R5 (no smooth time-invariant feedback; Brockett's necessary condition) [D2]** — if
  $\dot x = f(x,u)$ is locally asymptotically stabilised at the origin by a $C^1$ time-invariant
  feedback, the image of $(x,u)\mapsto f(x,u)$ must cover a neighbourhood of
  $0 \in \mathbb{R}^n$ (Brockett 1983, a book chapter with no permanent link; restated in
  Murray & Sastry 1993 §I). For (1), restricting to $\lvert\theta\rvert<\delta$ and
  $\lvert u\rvert<\delta$ makes $\dot q = (\cos\theta\,u_1,\ \sin\theta\,u_1,\ u_2)$ **unable to
  produce the lateral direction $(0,\epsilon,0)$ at all** — so (1) is not stabilisable by any
  smooth time-invariant feedback.

## Derivation

### R3 — second-order motion along a Lie bracket

Build (3) by Taylor expansion. Writing the flow to second order in $\varepsilon$, for any smooth
vector field $X$,

$$
\Phi^X_\varepsilon(x) = x + \varepsilon X(x) + \frac{\varepsilon^2}{2}\,\frac{\partial X}{\partial x}(x)X(x)
  + O(\varepsilon^3). \tag{6}
$$

(Differentiating $\frac{d}{dt}\Phi = X(\Phi)$ once more gives
$\ddot\Phi = \frac{\partial X}{\partial x}X$.) Abbreviate $A := \frac{\partial g_1}{\partial x}$
and $B := \frac{\partial g_2}{\partial x}$ and compose the four stages. Stage 1:

$$
x_1 = x + \varepsilon g_1 + \tfrac{\varepsilon^2}{2}Ag_1 + O(\varepsilon^3).
$$

Stage 2 must evaluate $g_2$ at $x_1$, so $g_2(x_1) = g_2 + \varepsilon B g_1 + O(\varepsilon^2)$:

$$
x_2 = x_1 + \varepsilon g_2(x_1) + \tfrac{\varepsilon^2}{2}(Bg_2)(x_1) + O(\varepsilon^3)
    = x + \varepsilon(g_1+g_2) + \varepsilon^2\!\left(\tfrac12 Ag_1 + Bg_1 + \tfrac12 Bg_2\right) + O(\varepsilon^3).
$$

Stage 3 evaluates $-g_1$ at $x_2$. With $g_1(x_2) = g_1 + \varepsilon A(g_1+g_2) + O(\varepsilon^2)$,

$$
x_3 = x_2 - \varepsilon g_1(x_2) + \tfrac{\varepsilon^2}{2}(Ag_1)(x_2) + O(\varepsilon^3)
    = x + \varepsilon g_2 + \varepsilon^2\!\left(Bg_1 + \tfrac12 Bg_2 - Ag_2\right) + O(\varepsilon^3).
$$

(The easy mistake is the sign: for the flow of $-g_1$ the second-order term of (6) is
$\frac{(-\varepsilon)^2}{2}\frac{\partial(-g_1)}{\partial x}(-g_1) = +\frac{\varepsilon^2}{2}Ag_1$,
**unchanged in sign**.) Stage 4 evaluates $-g_2$ at $x_3$ the same way; all first-order terms
cancel and

$$
x_4 = x + \varepsilon^2\big(Bg_1 - Ag_2\big) + O(\varepsilon^3)
    = x + \varepsilon^2[g_1,g_2](x) + O(\varepsilon^3), \tag{7}
$$

which is (3). **Numerical check**: for (1) at $\theta=0$, integrating the four segments for time
$\varepsilon$ each, the prediction from $[g_1,g_2](q)=(\sin\theta,-\cos\theta,0)^\top$ is
$(0,-\varepsilon^2,0)$, and for $\varepsilon = 0.1,\ 0.05,\ 0.02$ the residual norm is
$0.4999\varepsilon^3$, $0.5000\varepsilon^3$ and $0.5000\varepsilon^3$ — exactly third order. In
other words, **driving forward and back while turning the wheel in place pushes the robot
sideways by $\varepsilon^2$**: parallel parking is a Lie bracket.

The road to Chow-Rashevskii is visible here: if the brackets and their iterated brackets span
$\mathbb{R}^n$, motions of size $O(\varepsilon^2)$ (or $O(\varepsilon^k)$ for deeper brackets) can
be assembled in every direction and concatenated to reach any nearby point. The full proof shows
that the composition of motions is an open map (omitted: the standard proof of Chow's theorem,
MLS ch.7, or Sussmann's orbit theorem); this lesson derives only the **constructive step**.

**Where the assumptions break**: (3) is a local statement as $\varepsilon \to 0$. Because bracket
motion shrinks like $\varepsilon^2$, covering a lateral distance $d$ needs $O(d/\varepsilon^2)$
manoeuvres — "controllable" and "moves efficiently" are entirely different claims. The deeper the
bracket ($O(\varepsilon^3)$, $O(\varepsilon^4)$), the faster that cost grows, which is the root
reason nonholonomic motion planning is hard (it returns in `c6-nonholonomic-planning`).

### R4 — the chained-form transformation and steering with sinusoids

**Step 1 (deriving the transformation).** The $z_2, z_3$ of (4) are the position seen in the body
frame. Differentiating $z_2$,

$$
\dot z_2 = \dot x\cos\theta - x\sin\theta\,\dot\theta + \dot y\sin\theta + y\cos\theta\,\dot\theta
  = u_1(\cos^2\theta+\sin^2\theta) + u_2(-x\sin\theta + y\cos\theta) = u_1 - u_2 z_3,
$$

where the last equality holds because $-x\sin\theta+y\cos\theta = -z_3$. The same way,

$$
\dot z_3 = u_1\cos\theta\sin\theta - u_1\sin\theta\cos\theta + u_2(x\cos\theta + y\sin\theta) = u_2 z_2,
$$

and $\dot z_1 = u_2$. So changing the input to $v_1 := u_2$ and $v_2 := u_1 - u_2z_3$ gives

$$
\dot z_1 = v_1, \qquad \dot z_2 = v_2, \qquad \dot z_3 = z_2 v_1 \tag{8}
$$

with the inverse $u_2 = v_1$, $u_1 = v_2 + v_1 z_3$. The way back to the original coordinates is
needed too: $x = z_2\cos z_1 + z_3 \sin z_1$, $y = z_2 \sin z_1 - z_3\cos z_1$, $\theta = z_1$
(substitute to check).

**Step 2 (displacement over one period of sinusoids).** Put $v_1 = a\sin\omega t$,
$v_2 = b\cos\omega t$ in (8) and integrate to $T = 2\pi/\omega$:

$$
z_1(t) = z_1(0) + \frac{a}{\omega}(1-\cos\omega t), \qquad
z_2(t) = z_2(0) + \frac{b}{\omega}\sin\omega t,
$$

both returning **exactly** to their initial values at $t=T$. What is left is

$$
\Delta z_3 = \int_0^T z_2(t)v_1(t)\,dt
  = \underbrace{z_2(0)\,a\!\int_0^T\!\sin\omega t\,dt}_{=\,0}
  + \frac{ab}{\omega}\!\int_0^T\!\sin^2\omega t\,dt
  = \frac{ab}{\omega}\cdot\frac{T}{2} = \frac{\pi ab}{\omega^2}, \tag{9}
$$

which is (5). That the $z_2(0)$ term drops out is the key point — the displacement is
$\pi ab/\omega^2$ **regardless of where you start**.

**Step 3 (the parking algorithm).** The structure of (8) makes three segments enough. Map the goal
$q^\star=(x^\star,y^\star,\theta^\star)$ to $z^\star$ through (4), then:

- **A**: $v_2=0$ and $v_1$ constant, driving $z_1 \to z_1^\star$. ($z_2$ is unchanged; $z_3$ moves
  by $\int z_2v_1$.)
- **B**: the sinusoid pair, driving $z_3 \to z_3^\star$. $z_1$ and $z_2$ are back where they were
  at the end of the period. From the required $\Delta z_3$, (5) fixes
  $b = \Delta z_3\,\omega^2/(\pi a)$.
- **C**: $v_1 = 0$ and $v_2$ constant, driving $z_2 \to z_2^\star$. (Since $\dot z_3 = z_2v_1 = 0$,
  $z_3$ is preserved, and $z_1$ is unchanged.)

The order is A→B→C because C does not touch $z_3$ and B returns $z_1$ and $z_2$. Putting A last
would rotate $z_1$ while $z_2 \ne 0$ and spoil $z_3$ again.

**Numerical check**: solving $(0,0,0) \to (1,1,\pi/2)$ with one second per segment gives
$z^\star=(\pi/2, 1, 1)$, and with $\omega = 2\pi$ and $a=1$ in segment B, $b = 4\pi \approx
12.566371$; integrating the original system (1) with RK4 gives a terminal error of
$\lVert q(T)-q^\star\rVert_\infty \approx 2\cdot10^{-11}$.

**Where the assumptions break**: (4) treats $z_1 = \theta$ as an **unwrapped** angle. If $\theta$
is wrapped to $(-\pi,\pi]$, segment A turns the short way and accumulates a different $z_3$, so an
implementation must not wrap the angle and must instead **choose** which $\theta^\star + 2k\pi$ to
aim at. Also $b = \Delta z_3\omega^2/(\pi a)$ blows up when $\Delta z_3$ is large or $T$ short —
with input limits, the period has to be repeated and the displacement split ($N$ periods divide
each $b$ by $N$).

### R2 — input-output linearisation, and a point $d$ ahead of the wheel axle

Taking the robot's position $(x,y)$ as the output of (1) **fails**:

$$
\begin{bmatrix}\dot x\\ \dot y\end{bmatrix}
  = \begin{bmatrix}\cos\theta & 0\\ \sin\theta & 0\end{bmatrix}
    \begin{bmatrix}u_1\\u_2\end{bmatrix},
$$

the second column of the decoupling matrix is zero, so $u_2$ does not appear in the output at all.
But taking the output to be the point a distance $d>0$ ahead of the axle,
$h_d(q) = (x + d\cos\theta,\ y + d\sin\theta)$,

$$
\dot h_d = \underbrace{\begin{bmatrix}\cos\theta & -d\sin\theta\\
  \sin\theta & d\cos\theta\end{bmatrix}}_{=:J_d(\theta)}\begin{bmatrix}u_1\\u_2\end{bmatrix},
  \qquad \det J_d = d\,(\cos^2\theta+\sin^2\theta) = d. \tag{10}
$$

For $d \ne 0$, $J_d$ is invertible **at every $\theta$**, so $u = J_d^{-1}v$ gives
$\dot h_d = v$. The relative degree is 1 for each output and the remaining internal state is
one-dimensional ($\theta$). The input holding $h_d$ constant is $v=0$, i.e. $u=0$, and then
$\dot\theta = 0$: the zero dynamics are $\dot\eta = 0$, **neither stable nor unstable**
(marginally stable). So the forward point is tracked but the heading $\theta$ is not controlled.
That is why parking (which includes the heading) is still hard.

**Where the assumptions break**: as $d \to 0$, $\det J_d = d \to 0$ and
$\lVert J_d^{-1}\rVert$ blows up like $1/d$. A small $d$ "almost tracks the axle" but **commands
angular rates of order $1/d$** — the typical picture of a linearisation running into a
singularity. A large $d$ gives gentle commands but tracks a point far from the robot, which makes
obstacle avoidance a lie. $d$ is a trade between performance and conditioning.

The real trouble is when the zero dynamics are **unstable**. For instance,

$$
\dot\xi = u, \qquad \dot\eta = \eta + \xi, \qquad y = \xi \tag{11}
$$

has relative degree 1, and holding $y\equiv0$ requires $u\equiv0$, leaving $\dot\eta=\eta$ to
diverge: "exact tracking" **requires** the internal state to blow up. For such non-minimum-phase
systems the options are ⓐ approximate linearisation (Hauser et al. 1992: drop the small coupling
term, design, and bound the resulting error), ⓑ stable inversion (Devasia et al. 1996: solve for a
non-causal input using the future trajectory and recover exact tracking), or ⓒ changing the output
(as $h_d$ does). The assumptions and the costs of all three are the content of the must-read
papers.

### R5 — there is no smooth time-invariant feedback

Apply Brockett's necessary condition directly to (1). The question is whether, for arbitrarily
small $\delta$, the set $\{f(q,u) : \lvert q\rvert<\delta,\ \lvert u\rvert<\delta\}$ covers a
neighbourhood of $0 \in \mathbb{R}^3$. Its elements have the form
$(\cos\theta\,u_1,\ \sin\theta\,u_1,\ u_2)$. To produce the target vector $(0,\ \epsilon,\ 0)$:

- the third component forces $u_2 = 0$;
- the first forces $\cos\theta\,u_1 = 0$, and since $\lvert\theta\rvert<\delta < \pi/2$ we have
  $\cos\theta \ne 0$, hence $u_1 = 0$;
- then the second component is $\sin\theta\cdot 0 = 0 \ne \epsilon$.

So the image contains **no** lateral direction. The necessary condition fails, so (1) cannot be
asymptotically stabilised at the origin by any $C^1$ time-invariant feedback. That is why
**time-varying** strategies such as steering with sinusoids, or discontinuous ones, are
unavoidable.

**Where the assumptions break**: the conclusion needs all three of "smooth", "time-invariant" and
"a function of the state alone". Drop any one and a road opens — time-varying feedback (sinusoidal
steering), discontinuous feedback, or practical stabilisation to a set rather than a point. But
**every open road charges in robustness** (see the open problems).

## Proof sketch

### R1 — the condition for full feedback linearisation

**Hypotheses** H1: $f, g$ smooth near $x_0$ with $g(x_0)\ne0$.
H2: $\operatorname{rank}\{g,\operatorname{ad}_fg,\dots,\operatorname{ad}_f^{n-1}g\}(x_0) = n$.
H3: $\Delta_{n-1}=\operatorname{span}\{g,\dots,\operatorname{ad}_f^{n-2}g\}$ is involutive near $x_0$.
**Conclusion** C: there is an $h$ with $L_gh = L_gL_fh = \dots = L_gL_f^{n-2}h = 0$ and
$L_gL_f^{n-1}h \ne 0$; then $\xi = (h, L_fh, \dots, L_f^{n-1}h)$ is a coordinate system and an
input transformation of the form (2) linearises the system.

**Strategy**: turn "find a linearising output $h$" into "find a one-form $dh$ orthogonal to
$\Delta_{n-1}$", and trade the existence of that form for involutivity through the Frobenius
theorem.

1. **The conditions as a one-form.** Requiring $L_gL_f^kh = 0$ for $k \le n-2$ says that $dh$ is
   orthogonal to all of $g,\dots,\operatorname{ad}_f^{n-2}g$ (induct, using
   $L_{[X,Y]}h = L_XL_Yh - L_YL_Xh$). That is, $dh \perp \Delta_{n-1}$.
2. **Frobenius.** $\Delta_{n-1}$ has dimension $n-1$ by H2 and is involutive by H3. The Frobenius
   theorem: an involutive distribution of dimension $n-1$ is **integrable**, and locally there is
   an $h$ with $dh \ne 0$ and $\Delta_{n-1} = \ker dh$. That one line is where H3 is spent.
3. **The last derivative is non-zero.** By H2, $\operatorname{ad}_f^{n-1}g \notin \Delta_{n-1}$, so
   $L_gL_f^{n-1}h = \pm L_{\operatorname{ad}_f^{n-1}g}h \ne 0$ (the sign comes out of the bracket
   expansion). The denominator of (2) therefore survives.
4. **They are coordinates.** The Jacobian of $\xi_i = L_f^{i-1}h$ is non-singular by the
   orthogonality of steps 1 and 3 (omitted: linear independence of
   $d h, dL_fh, \dots$ — Khalil Lemma 13.1), and in those coordinates
   $\dot\xi_i = \xi_{i+1}$ for $i<n$ and $\dot\xi_n = L_f^nh + L_gL_f^{n-1}h\,u$, so (2) gives a
   linear system.
5. **The converse.** If the system is linearisable then $\xi_1$ provides the $h$ of step 1, and
   $\ker d\xi_1 = \Delta_{n-1}$ is integrable, hence involutive — so H3 is also **necessary**.

**Remove a hypothesis**: without H3 the $h$ of step 2 does not exist. (1) is exactly that case —
$\Delta = \operatorname{span}\{g_1,g_2\}$ is two-dimensional but $[g_1,g_2]\notin\Delta$, so it is
not involutive (check: $\det[g_1\ g_2\ [g_1,g_2]]=1\ne0$), and therefore no output linearises the
full state. The same bracket is the quantity that **gives controllability** in R3. This is not a
contradiction: a bracket leaving the distribution means both "we can move in a new direction"
(good) and "there is no integral surface" (no linearisation).

Technical steps omitted: the proof of the Frobenius theorem and the independence of
$\{dL_f^{i}h\}$. See Khalil ch.13.1 and Thm 13.2, MLS ch.7, or Isidori ch.4.

## Problem set

The solution policy is stated per problem. Difficulty: ★ 15 min / ★★ 1 hour / ★★★ a day or more.

**P1 (derivation, ★★, R4)** Recompute (9) with $v_1 = a\sin\omega t$ and
$v_2 = b\cos(k\omega t)$ for a positive integer $k$. For which $k$ is $\Delta z_3 = 0$, and how is
that fact used in a higher chained form (a system that also has $\dot z_4 = z_3v_1$)?
*Solution sketch*: orthogonality of $\int_0^T \sin\omega t\sin k\omega t\,dt$ kills the
contribution unless $k=1$. In the higher chained form, moving $z_4$ needs $\int z_3v_1$, and since
$z_3$ is itself an integral of a sine, the frequency ratio must be $k=2$ for the product of $z_3$
and $v_1$ to have non-zero mean — that computation is the general sinusoidal steering of
Murray & Sastry 1993 §III.

**P2 (proof, ★★★, R1·R3)** For (1), ⓐ show LARC holds using brackets, ⓑ show $\Delta$ is not
involutive, ⓒ explain with the statement of the Frobenius theorem why the two facts are not
contradictory.
*Solution sketch*: $[g_1,g_2]=(\sin\theta,-\cos\theta,0)^\top$ and
$\det[g_1\ g_2\ [g_1,g_2]]=1$. Frobenius says involutive $\Rightarrow$ a family of integral
surfaces exists, so failing to be involutive means "motion is not trapped on a surface", which is
exactly controllability.

**P3 (numerical, ★, R4)** Park from $(0,0,0)$ to $(1,1,\pi/2)$. With one second per segment and
$a=1$ in segment B, find ⓐ $z^\star$, ⓑ the $b$ of segment B, ⓒ the $v_1$ of segment A.
*Answers*: ⓐ $z^\star = (\pi/2,\ 1,\ 1)$ ⓑ $\omega = 2\pi$, so $b = 1\cdot(2\pi)^2/\pi = 4\pi
\approx 12.566371$ ⓒ $v_1 = \pi/2 \approx 1.5707963$ (tolerance $10^{-6}$).
Check: integrate (1) with RK4 ($\Delta t \le 10^{-4}$); a terminal error below $10^{-6}$ is correct
(the reference implementation reaches $2\cdot10^{-11}$).

**P4 (numerical, ★, R2)** For the $J_d$ of (10), find ⓐ $\det J_d$, ⓑ $J_d^{-1}$ at $\theta = 0$,
ⓒ the $u$ needed to move the forward point at velocity $(0, 1)$, as a function of $d$.
*Answers*: ⓐ $d$ ⓑ $J_d^{-1} = \begin{bmatrix}1 & 0\\ 0 & 1/d\end{bmatrix}$
ⓒ $u = (0,\ 1/d)$ — the angular rate blows up like $1/d$. Tolerance $10^{-9}$.

**P5 (implementation, ★★, R2)** Write a tracker that makes the forward point follow a circle by
input-output linearisation with $h_d$, and tabulate the maximum angular rate and the tracking error
for $d \in \{1, 0.3, 0.1, 0.03\}$.
*Rubric*: ⓐ shows the maximum $\lvert u_2\rvert$ growing roughly like $1/d$ ⓑ shows from the
trajectory that the heading $\theta$ is not controlled ⓒ states the criterion for choosing $d$ in
terms of conditioning and input limits.

**P6 (counterexample, ★★, R5)** Refute, in **two different ways**, the claim that (1) has been
asymptotically stabilised at the origin by a smooth time-invariant feedback $u = \kappa(q)$ with
$\kappa(0)=0$: (i) the image argument of R5, (ii) a specific feedback together with an equilibrium
other than the origin (or an initial condition that does not converge).
*Property checklist*: (i) states that the lateral direction is missing from the image, with the
$\delta$. (ii) for example a "gradient descent" feedback of the form
$u = (\,\cos\theta\,e_x + \sin\theta\,e_y,\ k\,\theta_{\text{err}})$ gives $u \equiv 0$ at
$q_0 = (0,0,0)$ with goal $(0,1,0)$, so the robot **does not move at all**.

## Reproduction task

**Tier R2 (re-implementation).** Budget: laptop CPU under ten minutes, numpy only. The system is
the differential-drive robot (1) and there is no input data — the goal poses are generated by the
script.

**Acceptance criteria (all four)**

1. **Transformation check**: for $10^4$ random $(q, u)$ (with $\lvert x\rvert,\lvert y\rvert \le 5$,
   $\theta \in (-\pi,\pi)$, $\lvert u\rvert \le 5$), the $\dot z$ obtained from (4) agrees with
   $(v_1,\ v_2,\ z_2v_1)$ of (8) to a maximum absolute error $< 10^{-10}$.
2. **One-period displacement**: for ten random triples
   $(a,b,\omega) \in [0.5,2]\times[0.5,10]\times[0.5,4]$, after one period
   $\lvert \Delta z_3 - \pi ab/\omega^2\rvert < 10^{-8}$ and
   $\lvert z_1(T)-z_1(0)\rvert, \lvert z_2(T)-z_2(0)\rvert < 10^{-8}$.
3. **Parking**: from $(0,0,0)$ to ⓐ the stated goal $(1,1,\pi/2)$ and ⓑ twenty random goals
   ($\lvert x^\star\rvert,\lvert y^\star\rvert \le 2$, $\theta^\star \in (-\pi,\pi)$),
   $\lVert q(T) - q^\star\rVert_\infty < 10^{-3}$ (RK4, $\Delta t \le 10^{-4}$, one second per
   segment). Report the maximum error over goals and the maximum $\lvert u_1\rvert$ and
   $\lvert u_2\rvert$ in a table.
4. **Contrast with Brockett**: run, on the same goals, the smooth time-invariant feedback
   $u_1 = k_1(\cos\theta\,e_x + \sin\theta\,e_y)$, $u_2 = k_2(\theta^\star-\theta)$ with
   $e = q^\star - q$ and any $k_i>0$, and show that for the **purely lateral goal** $(0,1,0)$ its
   terminal error is $\ge 0.9$ (that is, it effectively does not move), while sinusoidal steering
   reaches $<10^{-3}$ on the same goal.

**Baselines**: the smooth feedback of criterion 4 (which must fail) and the reference numbers of
criterion 3ⓐ (reference terminal error $2\cdot10^{-11}$, $b = 4\pi \approx 12.566371$).

**Failure diagnosis**

| Symptom | Cause | How to check |
|---|---|---|
| Parking leaves an $O(1)$ terminal error | the $z_3$ term of $u_1 = v_2 + v_1z_3$ was dropped (inverse transformation wrong) | pass criterion 1 first — if the transformation is wrong nothing else means anything |
| $z_1$ and $z_2$ do not return after segment B | the period is not exactly $T=2\pi/\omega$, or $\Delta t$ does not divide the period | take $\Delta t = T/N$ and double $N$: with RK4 the error should fall by 16 |
| Only goals with $\theta^\star$ near $\pm\pi$ fail | angle wrapping — $z_1=\theta$ was folded into $(-\pi,\pi]$ | choose the $\theta^\star+2k\pi$ with the smallest segment-A rotation and never wrap during integration |
| The inputs jump to hundreds | $b = \Delta z_3\omega^2/(\pi a)$ blows up for large $\Delta z_3$ | repeat the period $N$ times to divide $b$ by $N$ (the total displacement is the same) |
| The feedback of criterion 4 converges to the goal | a time-dependent or discontinuous term slipped into the feedback | check that $u$ is a continuous function of $q$ alone and that $u(q^\star)=0$ |

## Open problems

- **(open problem) Robustness of nonholonomic stabilisation** — time-varying and discontinuous
  feedbacks give convergence, but the rate degrades to something like $t^{-1/k}$ and the margin
  against model error is not quantified. Current approaches: the exponential stabilisation of
  [Sørdalen & Egeland 1995](https://doi.org/10.1109/9.362901) and the transverse function approach
  of [Morin & Samson 2003](https://doi.org/10.1109/TAC.2003.816963) (practical stabilisation to a
  set rather than a point). The gap: treating robustness margins under input limits and
  measurement noise as a design variable.
- **(open problem) Feedback linearisation on learned models** — the factor
  $1/L_gL_f^{\rho-1}h$ in (2) depends on the model through a **division**, so model error distorts
  the gain directly. Current approaches:
  [Westenbroek et al. 2019](https://arxiv.org/abs/1910.13272), compensating the linearisation
  error with reinforcement learning. The gap: conditions that preserve the relative degree and
  avoid singularities under a learned correction.
- **(open problem) Quantitative limits of approximate linearisation** — what quantity should
  measure the "slightly" of Hauser et al. 1992 at robot scale (articulated systems with contact
  and flexibility), and how much performance is lost when it is large, has no general bound. The
  gap: an explicit map from the size of the dropped term to a tracking-error bound.
- **(open problem) Joining planning and control** — steering with sinusoids knows nothing about
  obstacles. Complete methods that handle both the cost of bracket motion ($O(d/\varepsilon^2)$)
  and obstacle constraints are known only in low dimensions. `c6-nonholonomic-planning` meets the
  same problem from the planning side.

## How to study this stage

1. **Compute the bracket by hand (40 min)** — compute $[g_1,g_2]$ of (1) from the definition and
   check $\det[g_1\ g_2\ [g_1,g_2]]=1$. That single computation is half the lesson.
2. **Meet parallel parking in code (60 min)** — implement the four manoeuvres of (3) directly,
   watch the robot move sideways by $\varepsilon^2$, then halve $\varepsilon$ and confirm the
   displacement falls to a quarter. Once you have *seen* a Lie bracket you do not forget it.
3. **Memorise Frobenius as a statement only (40 min)** — the proof is not needed now. Learn
   precisely the link "involutive $\iff$ integrable" and "hence a linearising output exists";
   step 2 of R1 is that point. Read Khalil ch.13.1 against the same notation.
4. **Re-derive the chained-form transformation from blank paper (60 min)** — write out twice how
   differentiating (4) produces (8). The only trick is using
   $-x\sin\theta+y\cos\theta = -z_3$.
5. **Do the reproduction task in order (105 min)** — transformation check (1) → one-period
   displacement (2) → parking (3) → the Brockett contrast (4). In any other order you cannot tell
   what is wrong. **Do run criterion 4**: watching a smooth feedback sit still is the conclusion of
   this lesson.
6. **Read the papers for "what they gave up" (150 min)** — Murray & Sastry gave up optimality and
   got constructibility, Hauser gave up exactness and got causality, Devasia gave up causality and
   got exactness. Tabulating the three trades finishes this lesson.
7. **The bridge to the next lesson (20 min)** — feedback linearisation deals with *one*
   equilibrium. The view that compares *neighbouring trajectories* is
   `c3-contraction-incremental`, and there one searches for a **metric** instead of a change of
